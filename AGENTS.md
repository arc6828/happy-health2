# Project Customization Rules & Guidelines

## 📝 Document Formatting Rules for Academic Chapters

1) **Avoid Bullet Lists in Chapters**: When writing, updating, or editing thesis chapter documentation (under `docs/chapter1/`, `docs/chapter2/`, `docs/chapter3/`, `docs/chapter4/`, `docs/chapter5/`, etc.), **avoid using bullet point lists (`*` or `-`)**.
2) **Preferred Format**: Present academic content using formal paragraph prose or structured numbered format using **`1)`, `2)`, `3)`** or formal subsections (`4.1.1`, `4.1.2`) to adhere to Thai academic thesis standards.
