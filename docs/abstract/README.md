# บทคัดย่อการวิจัย (Research Abstracts)

เว็บไซต์อย่างเป็นทางการของโครงการ: **[https://happyhealthhappyheart.com](https://happyhealthhappyheart.com)**

โฟลเดอร์นี้รวบรวมบทคัดย่อโครงการวิจัย "การพัฒนาระบบให้คำปรึกษากับผู้ควบคุมน้ำหนักร่วมกับเจเนอเรทีฟเอไอ" (Happy Health Happy Heart) ทั้งภาษาไทยและภาษาอังกฤษ โดยแบ่งออกเป็นเอกสาร 2 ฉบับ ดังนี้:

1) [**บทคัดย่อภาษาไทย (Thai Abstract)**](abstract_th.md)
   สรุปวัตถุประสงค์การวิจัย ระเบียบวิธีวิจัย เทคโนโลยีระบบ (Laravel 12, Gemini 3.6 Flash API, LINE Webhook API) และผลสัมฤทธิ์เชิงตัวเลขในกลุ่มตัวอย่าง $n = 38$ ราย (น้ำหนักตัวลดลง 1.69 kg, BMI ลดลง 0.63, มวลกล้ามเนื้อเพิ่มขึ้น 0.70 kg, $p < .001$)

2) [**บทคัดย่อภาษาอังกฤษ (English Abstract)**](abstract_en.md)
   Comprehensive academic abstract in English presenting research objectives, system architecture, clinical methodology, statistical findings ($n = 38$, paired t-tests, 95% CI, p-values), and technological evaluations.
