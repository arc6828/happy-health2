## บทคัดย่อ

งานวิจัยเชิงพัฒนาและประยุกต์ใช้เทคโนโลยีนี้มีวัตถุประสงค์เพื่อออกแบบและพัฒนาแบบจำลองปัญญาประดิษฐ์เชิงสร้างสรรค์ (Generative AI) สำหรับการให้คำปรึกษาการควบคุมน้ำหนักเฉพาะบุคคล พัฒนาแพลตฟอร์มออนไลน์และระบบฐานข้อมูลสุขภาพที่มีความปลอดภัยตามมาตรฐานพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 (PDPA) ถ่ายทอดเทคโนโลยีการดูแลสุขภาพ อบรมความรู้โภชนาการ และสร้างคลังสื่อการเรียนรู้ดิจิทัล ตลอดจนประเมินผลสัมฤทธิ์ทางการแพทย์ของการจัดโปรแกรมแข่งขันลดน้ำหนัก ระบบพัฒนาขึ้นโดยใช้ Laravel Framework 12 เป็นสถาปัตยกรรมส่วนบริการหลังบ้าน เชื่อมต่อส่วนประสานผู้ใช้งาน Inertia.js, React.js และ LINE Messaging API ผ่าน Webhook API ประมวลผลร่วมกับแบบจำลองภาษาขนาดใหญ่ Google Gemini 3.6 Flash ผ่านกลไกสอดแทรกบริบทเฉพาะบุคคล (Personalized Context Injection) ซึ่งคำนวณค่า BMR, TDEE และติดตามน้ำหนักตัวรายวัน ร่วมกับระบบวิเคราะห์ภาพถ่ายอาหารเชิงหลากโหมด (Multimodal AI) ติดตั้งบนระบบโดเมนทางการ https://happyhealthhappyheart.com ผลการทดลองดำเนินโปรแกรมส่งเสริมสุขภาพระยะเวลา 8 สัปดาห์ ร่วมกับการประเมินผลเชิงการแพทย์ในกลุ่มตัวอย่างบุคลากรมหาวิทยาลัยจำนวน 38 ราย ($n = 38$) พบว่า ภายหลังเข้าร่วมโปรแกรม กลุ่มตัวอย่างมีองค์ประกอบร่างกายดีขึ้นอย่างมีนัยสำคัญทางสถิติในทุกตัวแปร ($p < .05$) โดยมีค่าน้ำหนักตัวลดลงเฉลี่ย 1.69 กิโลกรัม ($70.46 \pm 20.28$ เหลือ $68.77 \pm 19.46$ กิโลกรัม, $95\%\text{ CI: }1.02\text{ ถึง }2.19$, $t = 6.92$, $p < .001$) ค่าดัชนีมวลกายลดลงเฉลี่ย 0.63 กิโลกรัมต่อตารางเมตร ($24.84 \pm 3.60$ เหลือ $24.21 \pm 3.30$ กิโลกรัมต่อตารางเมตร, $95\%\text{ CI: }0.41\text{ ถึง }0.85$, $t = 5.96$, $p < .001$) และเปอร์เซ็นต์ไขมันในร่างกายลดลงเฉลี่ยร้อยละ 1.36 ($31.59 \pm 7.70$ เหลือ $30.11 \pm 7.68$ ร้อยละ, $95\%\text{ CI: }1.02\text{ ถึง }1.92$, $t = 6.67$, $p < .001$) โดยการลดลงของน้ำหนักมิได้เกิดจากการสูญเสียมวลสรีระที่ปราศจากไขมัน แต่นำไปสู่การเพิ่มขึ้นของมวลกล้ามเนื้ออย่างมีนัยสำคัญทางสถิติ 0.70 กิโลกรัม ($26.52 \pm 6.77$ เป็น $27.22 \pm 6.88$ กิโลกรัม, $95\%\text{ CI: }-1.25\text{ ถึง }-0.13$, $t = -2.51$, $p = .017$) ยืนยันถึงผลสัมฤทธิ์ในการสร้างสภาวะพร่องพลังงานอย่างถูกสุขลักษณะ นอกจากนี้ กลุ่มตัวอย่างมีคะแนนความรู้เกี่ยวกับหลัก 3 อ. (อาหาร ออกกำลังกาย อารมณ์) เพิ่มขึ้นจาก $11.26 \pm 2.06$ เป็น $13.45 \pm 1.42$ คะแนน ($p < .001$) และพฤติกรรมสุขภาพการดูแลตนเองโดยภาพรวมเพิ่มขึ้นจาก $1.66 \pm 0.42$ เป็น $2.36 \pm 0.17$ คะแนน ($p < .001$) ด้านประสิทธิภาพเทคโนโลยี ระบบมีเวลาการตอบสนองเฉลี่ย 2.4 วินาที มีความเสถียรภาพร้อยละ 99.8 และความพึงพอใจต่อการใช้งานระบบและกิจกรรมอบรมอยู่ในระดับมากที่สุด ($\bar{x} = 4.59 \pm 0.49$ และ $\bar{x} = 4.62 \pm 0.50$ ตามลำดับ) สรุปได้ว่า การบูรณาการเจเนอเรทีฟเอไอร่วมกับแพลตฟอร์มออนไลน์และกลไกเกมมิฟิเคชันสามารถส่งเสริมการกำกับตนเองเชิงพฤติกรรมสุขภาพ และอำนวยประโยชน์ต่อการจัดการน้ำหนักตัวอย่างมีประสิทธิภาพในระยะยาว

**คำสำคัญ**: เจเนอเรทีฟเอไอ, การควบคุมน้ำหนัก, โภชนาการเฉพาะบุคคล, แชตบอตสุขภาพ, เกมมิฟิเคชัน
