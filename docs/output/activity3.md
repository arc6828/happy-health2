## 1. รายละเอียดข้อมูลทางบรรณานุกรมของบทความวิจัย (Research Paper Metadata)

การเสนอผลงานวิจัยของโครงการได้รับการเรียบเรียงเป็นบทความวิจัยฉบับสมบูรณ์ภาษาอังกฤษ เพื่อให้สอดคล้องกับวัตถุประสงค์ในการเผยแพร่ผลงานวิชาการระดับนานาชาติในฐานข้อมูล Scopus โดยมีรายละเอียดที่ได้รับการยอมรับในการตีพิมพ์ดังต่อไปนี้

### 1.1 ข้อมูลทั่วไปของบทความ
1. **ชื่อบทความภาษาอังกฤษ**: Design and Development of a Personalized Weight Management Advisory Platform using Google Gemini Generative AI and LINE Messaging API
2. **ชื่อบทความภาษาไทย**: การออกแบบและพัฒนาแพลตฟอร์มให้คำปรึกษาการควบคุมน้ำหนักเฉพาะบุคคลด้วยปัญญาประดิษฐ์เชิงสร้างสรรค์ Google Gemini ร่วมกับ LINE Messaging API
3. **คณะผู้วิจัย**: ณรงค์ชัย โกศุวรรณ (Narongchai Kowsuwan), ประภาพรรณ พานิชสุข (Prapapan Panichsuk), และ สุรชัย อัศวรุ่งเรือง (Surachai Assawarungruang)
4. **วารสารเป้าหมายหลัก**: Suranaree Journal of Science and Technology (SJST)
5. **การจัดระดับวารสาร**: Scopus (Q4), TCI Tier 1, ACI

### 1.2 บทคัดย่อโดยสังเขป (Abstract Summary)
บทคัดย่อในงานวิจัยนี้กล่าวถึงปัญหาภาวะน้ำหนักเกินและโรคอ้วนในประเทศไทย โดยนำเสนอแนวทางแก้ไขผ่านการพัฒนาแพลตฟอร์มแชตบอตบน LINE Messaging API ร่วมกับสถาปัตยกรรม Google Gemini 2.0 Flash (`gemini-3.6-flash`) เพื่อให้คำปรึกษาด้านโภชนาการและการออกกำลังกายเฉพาะบุคคล ระบบนี้ใช้โปรโตคอล Dynamic Context Injection ในการคำนวณและป้อนข้อมูลสรีระร่างกาย (BMR และ TDEE) ไปยัง AI Prompt Context แบบเรียลไทม์ และติดตั้งกลไกความปลอดภัยเพื่อคัดกรองลิงก์ที่เป็นภัยคุกคาม ผลการทดลองในผู้ควบคุมน้ำหนักพบว่าระบบมีความแม่นยำด้านข้อมูลโภชนาการร้อยละ 92.00 และมีความเร็วเฉลี่ยในการตอบกลับ 2.4 วินาที ซึ่งผ่านเกณฑ์มาตรฐานการใช้งานบนระบบเครือข่าย

### 3.1 บันทึกสรุปข้อเสนอแนะและการแก้ไข (Peer Review Revision Summary)
