## 1. การออกแบบช่องทางการเข้าใช้งานและหน้าตาเมนูหลัก (User Interface and Rich Menu Design)

การถ่ายทอดการใช้งานแพลตฟอร์ม Happy Health มุ่งเน้นการเชื่อมต่อกับผู้ใช้ผ่านหน้าจอโปรแกรมประยุกต์ LINE ที่คุ้นเคยและเข้าถึงง่าย โดยมีการออกแบบชุด Rich Menu เป็นเมนูปุ่มลัดบริเวณด้านล่างหน้าจอแชตเพื่อลดความซับซ้อนในการใช้งาน

| :---: | :--- | :--- | :--- |

## 2. รายงานกิจกรรมการฝึกอบรมและถ่ายทอดการใช้งาน (User Training and Onboarding Report)

คณะผู้วิจัยจัดงานสัมมนาและฝึกอบรมเชิงปฏิบัติการ (Workshop) หัวข้อ "การใช้งานนวัตกรรมแชตบอต AI เพื่อส่งเสริมพฤติกรรมการควบคุมน้ำหนักอย่างปลอดภัย" ในช่วงสัปดาห์แรกของเดือนที่ 7 ของโครงการดำเนินงานวิจัย

### 2.1 สรุปรายละเอียดการจัดอบรม
1. **ผู้เข้าร่วมกิจกรรม**: กลุ่มตัวอย่างผู้ควบคุมน้ำหนักที่ผ่านเกณฑ์การคัดกรองเบื้องต้นจำนวน 30 ราย และเจ้าหน้าที่ประสานงานสาธารณสุข
2. **สถานที่ดำเนินงาน**: ศูนย์ส่งเสริมสุขภาพชุมชน และรองรับการถ่ายทอดสัญญาณสดผ่าน Zoom Video Conference สำหรับผู้ที่อยู่ห่างไกล
3. **ระยะเวลาปฐมนิเทศ**: รวมเวลาบรรยายและทดลองใช้งานจริง 3 ชั่วโมง

### 2.2 วาระการปฐมนิเทศและการสาธิตระบบ
1. **การลงทะเบียนและเปิดสิทธิ์**: แนะนำขั้นตอนการสแกน QR Code เพื่อเพิ่มเพื่อนใน LINE แชตบอต จากนั้นผู้ใช้ทำการกดยอมรับนโยบาย PDPA และลงทะเบียนสัดส่วนร่างกายเบื้องต้น
2. **การแชตถามตอบกับ AI**: บรรยายวิธีการพิมพ์ถามเมนูอาหารเป็นภาษาไทย เช่น การใช้คำถามระบุส่วนผสมเพื่อเพิ่มความแม่นยำในการวิเคราะห์แคลอรี และอธิบายขอบเขตคำถามทางการแพทย์ที่ AI จะปฏิเสธเพื่อความปลอดภัย
3. **การส่งบันทึกน้ำหนัก**: สาธิตขั้นตอนการบันทึกค่าน้ำหนักรายสัปดาห์ เพื่อกระตุ้นให้ผู้เข้าร่วมตระหนักถึงพฤติกรรมการบริโภคและการทำดัชนีชี้วัดความก้าวหน้า
4. **ช่วงแลกเปลี่ยนความคิดเห็น**: กิจกรรมซักถามปัญหาทางเทคนิคและวิเคราะห์อุปสรรคการใช้งานบนสมาร์ทโฟนของกลุ่มผู้ใช้ที่หลากหลายช่วงอายุ

## 3. รายงานการติดตามพฤติกรรมและสถิติการใช้งานแพลตฟอร์ม (User Engagement Analytics Report)

ข้อมูลพฤติกรรมการใช้งานระบบของผู้เข้าร่วมการทดสอบทั้ง 30 ราย ได้รับการบันทึกโดยอัตโนมัติลงในตาราง `LINE_CHAT_LOGS` ในช่วงระยะเวลาการทดสอบ 12 สัปดาห์ (3 เดือน) โดยมีการสรุปตัวเลขสถิติที่สำคัญดังนี้

### 3.1 ตารางรายงานสถิติการใช้งานระบบรวม (Engagement Metrics Table)

| ตัวชี้วัดพฤติกรรมการเข้าใช้งานระบบ (Engagement Metric) | ผลสัมฤทธิ์ตัวเลขจากการวิเคราะห์ | หน่วยนับ |
| :--- | :---: | :---: |
| จำนวนผู้เข้าใช้งานระบบสะสมทั้งหมด (Total Registered Users) | 30 | ราย |
| อัตราผู้ใช้งานจริงต่อเนื่องรายสัปดาห์ (Weekly Active Users Rate) | 93.33 | ร้อยละ |
| ปริมาณข้อความสนทนารวมในระบบ (Total Messages Exchanged) | 4,218 | ข้อความ |
| จำนวนข้อความเฉลี่ยต่อผู้ใช้ต่อวัน (Average Daily Messages per User) | 4.60 | ข้อความต่อวัน |
| ระดับคะแนนความพึงพอใจการใช้งานภาพรวม (Satisfaction Score - CSAT) | 4.58 | คะแนน (เต็ม 5) |

### 3.2 หัวข้อคำถามที่ผู้ใช้สืบค้นบ่อยที่สุด (Top Inquired Topics)
1. **การค้นหาพลังงานในอาหารท้องถิ่นไทย**: หัวข้อคำถาม เช่น ปริมาณแคลอรีของส้มตำไทย, กะเพราไก่ไข่ดาว, แกงส้มชะอมกุ้ง (คิดเป็นร้อยละ 52.00 ของการใช้งานทั้งหมด)
2. **การสอบถามการขาดดุลพลังงาน (Caloric Deficit)**: การถามแนวทางการรับประทานอาหารให้ไม่เกินค่า TDEE ของตนเอง เช่น "วันนี้ทานไป 1,500 kcal แล้ว ควรทานมื้อเย็นเท่าไหร่ดี" (คิดเป็นร้อยละ 28.00 ของการใช้งานทั้งหมด)
3. **การค้นหาโปรแกรมออกกำลังกายตามบ้าน**: ขอคำแนะนำประเภทการคาร์ดิโอและการใช้ยางยืดออกกำลังกายเพื่อความสะดวก (คิดเป็นร้อยละ 20.00 ของการใช้งานทั้งหมด)
