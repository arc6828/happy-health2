# บทที่ 1: บทนำ (Introduction)

รายงานวิจัยฉบับนี้เสนอการออกแบบ การพัฒนา และการประเมินผลระบบให้คำปรึกษาสำหรับผู้ควบคุมน้ำหนัก โดยบูรณาการเทคโนโลยีปัญญาประดิษฐ์เชิงสร้างสรรค์ (Generative AI) ร่วมกับแพลตฟอร์มแชตบอต LINE เพื่อเป็นทางเลือกในการส่งเสริมสุขภาพและการควบคุมน้ำหนักของผู้ใช้งานอย่างมีประสิทธิภาพ

## 1.1 ความเป็นมาและความสำคัญ

ปัจจุบันปัญหาโรคอ้วนและภาวะน้ำหนักเกินเป็นความท้าทายทางสาธารณสุขที่สำคัญทั้งในระดับโลกและในประเทศไทย ซึ่งส่งผลให้เกิดโรคไม่ติดต่อเรื้อรัง (NCDs) เช่น โรคเบาหวานและโรคหลอดเลือดหัวใจที่มีอัตราผู้ป่วยพุ่งสูงขึ้นอย่างต่อเนื่อง โดยมีพฤติกรรมการบริโภคอาหารพลังงานสูงและการขาดการทำกิจกรรมทางกายเป็นปัจจัยร่วมที่สำคัญ อย่างไรก็ตาม การควบคุมน้ำหนักให้ประสบความสำเร็จอย่างยั่งยืนนั้น จำเป็นต้องอาศัยความรู้ความเข้าใจอย่างเฉพาะเจาะจงในแต่ละบุคคล (Personalization) ทั้งในมิติด้านโภชนาการ การจัดการแคลอรี และการออกแบบตารางออกกำลังกาย ซึ่งการวิเคราะห์ข้อมูลสุขภาพเหล่านี้มีความซับซ้อนและจำเป็นต้องได้รับการแนะนำอย่างเหมาะสมและต่อเนื่อง

ในทางปฏิบัติ การเข้าถึงคำปรึกษาเฉพาะทางจากแพทย์ นักโภชนาการ หรือเทรนเนอร์ส่วนบุคคลมักมีข้อจำกัดอย่างมาก ทั้งในเรื่องค่าใช้จ่ายที่สูงและข้อจำกัดด้านเวลา ทำให้บริการสุขภาพแบบดั้งเดิมไม่สามารถตอบสนองความต้องการของผู้ควบคุมน้ำหนักได้อย่างทั่วถึงตลอด 24 ชั่วโมง ด้วยเหตุนี้ การพัฒนาอย่างก้าวกระโดดของเทคโนโลยีเจเนอเรทีฟเอไอ (Generative AI) และโมเดลภาษาขนาดใหญ่ (Large Language Models: LLMs) เช่น Google Gemini จึงเข้ามามีบทบาทสำคัญในการเป็นเครื่องมือช่วยสนับสนุน โดยระบบคอมพิวเตอร์มีความสามารถในการทำความเข้าใจภาษาธรรมชาติ วิเคราะห์บริบทสุขภาพเฉพาะบุคคล และโต้ตอบเพื่อแนะแนวพฤติกรรมสุขภาพได้รวดเร็วและเป็นธรรมชาติใกล้เคียงกับผู้เชี่ยวชาญมนุษย์

คณะผู้วิจัยจึงได้เล็งเห็นถึงความสำคัญดังกล่าว และมุ่งพัฒนาระบบให้คำปรึกษากับผู้ควบคุมน้ำหนักร่วมกับเจเนอเรทีฟเอไอ โดยบูรณาการระบบหลังบ้านที่พัฒนาด้วย Laravel Framework และระบบฐานข้อมูล SQLite หรือ MySQL สำหรับเก็บบันทึกประวัติการปรึกษา เข้ากับโมเดล Generative AI (Gemini 2.0 Flash) ผ่านส่วนติดต่อผู้ใช้งานบนแอปพลิเคชัน LINE ซึ่งเป็นแพลตฟอร์มที่เข้าถึงง่ายและผู้ใช้งานคุ้นเคยเป็นอย่างดี เพื่อทำหน้าที่เป็นผู้ช่วยส่วนตัวในการให้คำปรึกษา แนะนำโภชนาการ และการออกกำลังกายเบื้องต้นที่เข้าถึงได้สะดวกรวดเร็วตลอด 24 ชั่วโมง ตลอดจนสนับสนุนการจัดเก็บและวิเคราะห์พฤติกรรมสุขภาพย้อนหลังอย่างมีประสิทธิภาพ

## 1.2 วัตถุประสงค์ของการวิจัย

1) **1.2.1** เพื่อออกแบบและพัฒนาแบบจำลอง AI สำหรับการให้คำปรึกษาผู้ควบคุมน้ำหนัก ฝึกฝนแบบจำลองด้วยข้อมูลที่รวบรวมมา โดยสามารถวิเคราะห์และให้คำแนะนำได้อย่างแม่นยำ
2) **1.2.2** เพื่อออกแบบและพัฒนาแพลตฟอร์มออนไลน์ที่ผู้ควบคุมน้ำหนักสามารถเข้าถึงได้ง่าย โดยรวมฟังก์ชันการให้คำปรึกษาจาก AI การบันทึกและติดตามข้อมูลสุขภาพ การแจ้งเตือน และการสนับสนุนผู้ควบคุมน้ำหนัก จัดทำฐานข้อมูลที่มีความปลอดภัยและเป็นส่วนตัว เพื่อเก็บรักษาข้อมูลของผู้ควบคุมน้ำหนัก และถ่ายทอดการใช้งานแพลตฟอร์มออนไลน์การดูแลสุขภาพสำหรับผู้ควบคุมน้ำหนัก ติดตามการใช้งานและผลลัพธ์จากผู้ควบคุมน้ำหนักที่ใช้แพลตฟอร์ม
3) **1.2.3** เพื่ออบรมและสนับสนุนความรู้ผู้ควบคุมน้ำหนักด้วยข้อมูลโภชนาการด้วยเนื้อหาที่ถูกต้องเหมาะสม รวมทั้งให้คำปรึกษาด้านโภชนาการและการสนับสนุนทางเทคนิคสำหรับผู้ควบคุมน้ำหนัก
4) **1.2.4** เพื่อจัดการแข่งขันการลดน้ำหนัก โดยมีการรวบรวมข้อมูลทางการแพทย์ที่เกี่ยวข้อง และประเมินผลลัพธ์ของการควบคุมน้ำหนัก รวมถึงให้คำปรึกษาด้านการออกกำลังกาย

## 1.3 ขอบเขตของการวิจัย

ขอบเขตของการวิจัยในโครงการนี้ครอบคลุมการดำเนินงานทั้งในด้านโครงสร้างทางเทคโนโลยี ซอฟต์แวร์ และเนื้อหาด้านการประมวลผลคำแนะนำสุขภาพ ดังนี้

### 1.3.1 ขอบเขตด้านเทคโนโลยีและซอฟต์แวร์
การออกแบบและพัฒนาแพลตฟอร์มออนไลน์เพื่อสุขภาพในงานวิจัยนี้ ประกอบด้วยโครงสร้างทางเทคโนโลยีที่ใช้ในการดำเนินงานดังต่อไปนี้:
1) **ระบบส่วนบริการหลังบ้าน (Backend Framework)**: พัฒนาขึ้นโดยใช้ Laravel Framework เวอร์ชัน 12 ในรูปแบบ RESTful API เพื่อใช้ในการประมวลผลระบบและจัดการข้อมูล
2) **ระบบแสดงผลส่วนหน้าบ้าน (Frontend Dashboard)**: พัฒนาส่วนควบคุมข้อมูลการใช้งานและระบบจัดการบันทึกด้วย React และ TypeScript ผ่านเทคโนโลยี Inertia.js เพื่อจัดทำหน้าจอแดชบอร์ดหลังบ้าน
3) **ส่วนติดต่อประสานงานผู้ใช้งาน (User Interface)**: ประยุกต์ใช้แอปพลิเคชัน LINE ร่วมกับ LINE Messaging API ในการรับส่งข้อความเพื่อโต้ตอบข้อมูลสุขภาพกับผู้ใช้งานปลายทาง
4) **แบบจำลองปัญญาประดิษฐ์ (Generative AI)**: เรียกใช้บริการผ่าน Google Gemini API โดยกำหนดใช้โมเดลรุ่น `gemini-3.6-flash` สำหรับการถอดความหมาย วิเคราะห์เจตนา และสร้างข้อความตอบกลับภาษาไทย
5) **ระบบการจัดการฐานข้อมูล (Database)**: ใช้ระบบฐานข้อมูล SQLite หรือ MySQL ในการบันทึกประวัติกิจกรรมและการสนทนาระหว่างผู้ใช้งานกับระบบผ่านตาราง `line_chat_logs` โดยระบุจัดเก็บฟิลด์ข้อมูลที่สำคัญ ได้แก่ รหัสผู้ใช้ คำถาม คำตอบ และวันเวลาที่เกิดกิจกรรม

### 1.3.2 ขอบเขตด้านเนื้อหาและการดำเนินงานระบบ
ขอบเขตการจัดทำเนื้อหาข้อมูลสุขภาพและการโต้ตอบให้คำแนะนำแก่ผู้ใช้งาน กำหนดกรอบการดำเนินงานไว้ดังนี้:
1) **กลุ่มเป้าหมายและการทดสอบระบบ**: กลุ่มตัวอย่างที่ใช้ในการทดสอบและประเมินระบบจะเป็นกลุ่มบุคคลวัยผู้ใหญ่ทั่วไปที่ต้องการดูแลสุขภาพและควบคุมน้ำหนักตัว โดยงานวิจัยนี้ไม่รวมผู้ใช้ที่มีโรคประจำตัวร้ายแรงหรือข้อจำกัดด้านสุขภาพเฉพาะตัว เช่น ผู้ป่วยโรคเบาหวานขั้นรุนแรง หรือผู้มีภาวะโรคหัวใจ เพื่อป้องกันความเสี่ยงจากการนำคำแนะนำทั่วไปของระบบไปใช้
2) **ขอบเขตการให้คำปรึกษาด้านโภชนาการและการออกกำลังกาย**: ระบบจะจำกัดขอบเขตการตอบคำถามอยู่เฉพาะข้อมูลพื้นฐานด้านโภชนาการ เช่น ปริมาณพลังงานในอาหารและแผนการกินที่เหมาะกับการควบคุมน้ำหนักเบื้องต้น แต่จะไม่ครอบคลุมถึงการกำหนดโภชนบำบัดเฉพาะรายโรค ในส่วนด้านกิจกรรมทางกายจะจำกัดอยู่เพียงระดับเริ่มต้นและระดับปานกลาง เช่น การทำกิจกรรมคาร์ดิโอและการยืดเหยียดทั่วไป ไม่ครอบคลุมถึงโปรแกรมการฝึกที่ต้องควบคุมใกล้ชิดโดยผู้ฝึกสอนส่วนบุคคล
3) **ขอบเขตการประมวลผลข้อมูลส่วนบุคคล**: ระบบทำการประมวลข้อมูลพื้นฐานของผู้ใช้งาน เช่น น้ำหนัก ส่วนสูง พฤติกรรมการบริโภคและการออกกำลังกาย เพื่อนำมาสร้างคำแนะนำที่เหมาะสมเป็นรายบุคคล โดยมีระบบความปลอดภัยและรักษาความเป็นส่วนตัวของข้อมูลผู้ใช้งาน และไม่ครอบคลุมการวิเคราะห์ข้อมูลประวัติการรักษาทางการแพทย์ที่มีความละเอียดอ่อนสูง
4) **ขอบเขตการตอบสนองของระบบปัญญาประดิษฐ์ (Generative AI)**: การประมวลผลของโมเดลปัญญาประดิษฐ์ถูกควบคุมให้จำกัดบทบาทเฉพาะการให้คำปรึกษาและการสนับสนุนข้อมูลความรู้เบื้องต้นตามข้อมูลที่ได้รับจากผู้ใช้เท่านั้น ไม่สามารถใช้วินิจฉัยหรือสั่งการรักษาโรคทดแทนแพทย์ได้ โดยระบบจะทำการคัดกรองลิงก์เชื่อมโยง (URL) ที่ส่งเข้ามาเพื่อความปลอดภัยของเซิร์ฟเวอร์ และควบคุมผลลัพธ์คำตอบให้กระชับและจบภายใน 1 ย่อหน้าเพื่อให้อ่านเข้าใจได้สะดวกผ่านสมาร์ตโฟน
5) **กรอบระยะเวลาและการประเมินผลระบบ**: การทดสอบระบบจะจำกัดกรอบการเก็บข้อมูลและการทดลองใช้งานร่วมกับกลุ่มตัวอย่างในระยะเวลาที่กำหนด (ประมาณ 3 ถึง 6 เดือน) โดยจะเน้นการวัดผลเชิงคุณภาพในประเด็นระดับความพึงพอใจ ความสม่ำเสมอในการเข้าใช้งาน ความน่าเชื่อถือ และความแม่นยำของข้อมูลคำแนะนำที่ได้จากระบบเป็นสำคัญ

## 1.4 ข้อจำกัดของการวิจัย

ข้อจำกัดของงานวิจัยประกอบด้วยโอกาสความคลาดเคลื่อนในการประมวลผลข้อมูลและให้แนะนำของ Generative AI ในบางกรณี รวมถึงข้อจำกัดเชิงการปรับตัวของผู้ใช้งานในการปรับพฤติกรรมตามแผนการแนะนำจริง นอกจากนี้ โครงการวิจัยยังมีข้อจำกัดในแง่ของระยะเวลาและงบประมาณสำหรับการพัฒนา ตลอดจนการขยายขีดความสามารถการทดสอบระบบในกลุ่มตัวอย่างวงกว้าง

## 1.5 สมมติฐานการวิจัย

เนื่องจากงานวิจัยนี้เป็นการวิจัยเชิงพัฒนาและประยุกต์ใช้เทคโนโลยี (Developmental and Applied Research) จึงไม่มีการตั้งสมมติฐานการวิจัยทางสถิติอย่างเป็นทางการ อย่างไรก็ตาม คณะผู้วิจัยตั้งสมมติฐานเชิงพฤติกรรมว่า การพัฒนาแพลตฟอร์มแนะนำสุขภาพที่สะดวกและรวดเร็วผ่านแชตบอต Generative AI จะช่วยกระตุ้นความตระหนักรู้และส่งเสริมให้ผู้ใช้งานติดตาม ตลอดจนปรับเปลี่ยนพฤติกรรมการบริโภคอาหารและการออกกำลังกายให้เหมาะสมยิ่งขึ้นได้

## 1.6 คำจำกัดความที่ใช้ในงานวิจัย

1) **เจเนอเรทีฟเอไอ (Generative AI)** หมายถึง เทคโนโลยีปัญญาประดิษฐ์เชิงสร้างสรรค์ที่ทำงานร่วมกับโมเดลภาษาขนาดใหญ่ (LLMs) โดยในการศึกษาครั้งนี้ใช้ Google Gemini (โมเดล `gemini-3.6-flash`) เพื่อประมวลผลและสร้างข้อความแนะนำสุขภาพภาษาไทย
2) **ผู้ควบคุมน้ำหนัก** หมายถึง บุคคลวัยผู้ใหญ่ที่ประสงค์จะเข้าร่วมการทดลองใช้งานระบบ เพื่อปรับพฤติกรรมการบริโภคอาหารและการออกกำลังกายสำหรับควบคุมหรือลดน้ำหนัก
3) **แพลตฟอร์มออนไลน์การดูแลสุขภาพ** หมายถึง ระบบแอปพลิเคชันที่สร้างขึ้นโดยเชื่อมโยง Laravel Backend และระบบบันทึกฐานข้อมูล SQLite หรือ MySQL เข้ากับแอปพลิเคชัน LINE เพื่อดำเนินงานรับส่งข้อมูลคำปรึกษาและติดตามความก้าวหน้า
4) **ข้อมูลโภชนาการและการออกกำลังกาย** หมายถึง ข้อมูลและคำแนะนำพื้นฐานในมิติการบริโภคอาหาร เช่น ปริมาณแคลอรี และการทำกิจกรรมทางกายขั้นต้นหรือขั้นปานกลางที่ไม่ซับซ้อน

## 1.7 ประโยชน์ที่คาดว่าจะได้รับ

1) **1.7.1** ได้โมเดลด้านภาษาและแชตบอตโต้ตอบการให้คำปรึกษาอัตโนมัติสำหรับผู้ควบคุมน้ำหนัก โดยพัฒนาและนำเสนอแพลตฟอร์มที่ทำงานร่วมกับ Generative AI ที่สามารถให้คำแนะนำและคำปรึกษาด้านโภชนาการ การออกกำลังกาย และการดูแลสุขภาพด้านอื่น ๆ ได้ตลอด 24 ชั่วโมง
2) **1.7.2** ได้ฐานข้อมูลเก็บประวัติผู้ควบคุมน้ำหนักและการวิเคราะห์สุขภาพ โดยสร้างระบบจัดเก็บข้อมูลเกี่ยวกับน้ำหนัก การออกกำลังกาย และสถิติสุขภาพอื่น ๆ ที่เกี่ยวข้อง เพื่อนำมาใช้วิเคราะห์ข้อมูลเชิงลึกสนับสนุนการลดน้ำหนัก
3) **1.7.3** ได้แพลตฟอร์มออนไลน์ที่ช่วยให้ผู้ควบคุมน้ำหนักสามารถเข้าถึงคำแนะนำได้สะดวก มีฟังก์ชันบันทึกและติดตามสถิติสุขภาพ มีระบบแจ้งเตือนตรวจสอบน้ำหนักและกิจกรรมสำคัญ รวมถึงจัดโปรแกรมการฝึกอบรมการใช้งานร่วมกับปัญญาประดิษฐ์ให้กับกลุ่มตัวอย่าง
4) **1.7.4** ได้ฐานข้อมูลสื่อการศึกษาและสนับสนุนความรู้ด้านโภชนาการ การออกกำลังกาย และการดูแลสุขภาพทั่วไปผ่านสื่อออนไลน์ วิดีโอ ใบปลิว หรือแผ่นพับที่เป็นประโยชน์ โดยแบ่งสัดส่วนเนื้อหาด้านโภชนาการร้อยละ 80 และเนื้อหาด้านการออกกำลังกายกับการดูแลสุขภาพทั่วไปร้อยละ 20
5) **1.7.5** ผลงานวิจัยได้รับการตีพิมพ์เผยแพร่ในวารสารทางวิชาการระดับนานาชาติที่ยอมรับในฐานข้อมูล Scopus จำนวน 1 บทความ
