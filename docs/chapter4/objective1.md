# 4.1 ผลการวิเคราะห์ ออกแบบ และพัฒนาแบบจำลอง AI สำหรับการให้คำปรึกษา (สอดคล้องกับวัตถุประสงค์ข้อที่ 1.2.1)

ผลการดำเนินงานด้านการออกแบบและปรับแต่งโมเดลปัญญาประดิษฐ์เพื่อช่วยให้คำปรึกษาสุขภาพเฉพาะบุคคล มีผลลัพธ์ดังนี้:

### 4.1.1 สถาปัตยกรรมและกลไกการเรียนรู้บริบท
คณะผู้วิจัยพัฒนาแบบจำลอง AI โดยเรียกใช้งานโมเดล `gemini-3.6-flash` ของ Google ผ่าน API โดยกำหนด System Instruction และการทำ Prompt Engineering เพื่อบังคับขอบเขตองค์ความรู้ให้อยู่ในกรอบสุขอนามัย โภชนาการ และการจัดตารางออกกำลังกายระดับปลอดภัย รวมทั้งกำหนดคำสั่งควบคุมขนาดความยาวคำตอบโดยต่อสร้อยคำถามผู้ใช้ด้วยประโยค **" ไม่เกิน 1 ย่อหน้า"** เพื่อลดระดับการคำนวณและลดโอกาสการเกิดเนื้อหาคลาดเคลื่อน (AI Hallucination)

### 4.1.2 กลไกปัญญาประดิษฐ์ระดับสูงในการวิเคราะห์และตอบสนอง (Advanced AI Mechanisms)
คณะผู้วิจัยได้บูรณาการกลไกการคำนวณระดับสูง 2 ส่วนในโมเดลปัญญาประดิษฐ์เพื่อช่วยยกระดับความแม่นยำในการให้คำปรึกษาเฉพาะบุคคล:

1) **ระบบแนะแนวสุขภาพแบบผูกพันโปรไฟล์ร่างกาย (Personalized Context Injection)**
   หากบัญชีไลน์ของผู้ใช้งานเชื่อมโยงอยู่กับฐานข้อมูลโปรไฟล์ในระบบหลังบ้าน ระบบหลังบ้านของ Laravel จะดึงข้อมูลร่างกายล่าสุดของผู้ใช้นั้นโดยอัตโนมัติ (เพศ, อายุ, ส่วนสูง, ค่าน้ำหนักตัวล่าสุดจาก `user_health_logs` และระดับการทำกิจกรรม) เพื่อประกอบเข้าเป็นข้อมูลบริบทประวัติทางกายภาพ (Personalized Context) จากนั้นนำมาสอดแทรกก่อนคำถามของผู้ใช้เพื่อส่งให้ Google Gemini API ประมวลผล ช่วยให้ปัญญาประดิษฐ์สามารถคำนวณและปรับเปลี่ยนระดับเป้าหมายแคลอรี่และการแนะนำโภชนาการให้สอดคล้องกับค่า BMR และ TDEE ของผู้ใช้งานเฉพาะบุคคลได้อย่างมีนัยสำคัญโดยที่ผู้ใช้ไม่ต้องคอยระบุข้อมูลร่างกายซ้ำทุกครั้งที่แชต

2) **ระบบการวิเคราะห์และประเมินแคลอรี่จากรูปถ่ายอาหาร (Multimodal Food Image Recognition)**
   แบบจำลองสนับสนุนการประมวลผลอินพุตแบบหลายมิติ (Multimodal AI) เมื่อผู้ใช้งานอัปโหลดรูปภาพอาหารผ่านหน้าต่างแชตของ LINE OA ระบบหลังบ้านจะดึงไฟล์ภาพจาก LINE Content API มาแปลงรหัสเป็น Base64 และส่งต่อไปยังโมเดล `gemini-3.6-flash` เพื่อทำการสแกนประเมินผลลัพธ์ในลักษณะการระบุชื่อเมนูอาหาร ประมาณการค่าน้ำหนักพลังงานความร้อน (กิโลแคลอรี่) และวิเคราะห์สัดส่วนสารอาหารหลัก (Carbohydrate, Protein, Fat) พร้อมข้อแนะนำในการบริโภคที่ปลอดภัย สรุปจบภายใน 1 ย่อหน้า

### 4.1.3 ผลการทดสอบกรณีการใช้งาน (Use Case Scenarios)
คณะผู้วิจัยและผู้เชี่ยวชาญด้านโภชนาการร่วมทำการตรวจสอบคุณภาพความตรงเชิงเนื้อหาในการตอบคำถามของเอไอผ่านการป้อนคำถามจำลอง 4 รูปแบบหลัก:

1) **กรณีทดสอบที่ 1: การคำนวณพลังงานอาหารไทย**
   - *คำถามผู้ใช้ (Prompt)*: "ข้ามันไก่ผสมไก่ทอด 1 จาน มีแคลอรี่เท่าไหร่ และสำหรับคนคุมน้ำหนักควรกินอย่างไรครับ"
   - *คำตอบจาก AI (Reply)*: "ข้าวมันไก่ผสมไก่ทอด 1 จาน ให้พลังงานสูงประมาณ 700 - 850 กิโลแคลอรี เนื่องจากตัวข้าวหุงด้วยน้ำมันไก่และมีไก่ส่วนที่ชุบแป้งทอดซ้ำ หากคุณกำลังควบคุมน้ำหนัก แนะนำให้เลี่ยงส่วนที่เป็นไก่ทอดและหนังไก่ โดยสั่งเป็น 'ข้าวมันอกไก่ไม่เอาหนัง' หรือเปลี่ยนข้าวเป็น 'ข้าวสวยธรรมดา' ซึ่งจะช่วยลดพลังงานสะสมลงไปได้กว่า 200-300 กิโลแคลอรี และควรรับประทานผักเคียงร่วมด้วยเพื่อเพิ่มกากใยอาหารครับ"
   - *ผลประเมิน*: คำแนะนำมีความถูกต้องตามหลักโภชนาการ สุภาพ และสั้นกระชับจบภายใน 1 ย่อหน้าตามโครงสร้างคำสั่งควบคุม

2) **กรณีทดสอบที่ 2: การแนะแนวโปรแกรมคาร์ดิโอสำหรับผู้มีน้ำหนักตัวมาก**
   - *คำถามผู้ใช้ (Prompt)*: "น้ำหนัก 90 กิโล อยากเริ่มออกกำลังกายลดน้ำหนัก ช่วยแนะนำคาร์ดิโอหน่อยครับ"
   - *คำตอบจาก AI (Reply)*: "สำหรับผู้ที่มีน้ำหนักตัว 90 กิโลกรัม ควรเริ่มต้นออกกำลังกายคาร์ดิโอที่มีแรงกระแทกต่ำ (Low-impact) เพื่อป้องกันความเสี่ยงต่อข้อเข่าและข้อเท้า แนะนำให้ฝึกด้วยการเดินเร็ว (Power Walking) วันละ 30-45 นาที หรือการปั่นจักรยานอยู่กับที่ และการว่ายน้ำ สัปดาห์ละ 3-4 วัน หลีกเลี่ยงการวิ่งจ๊อกกิ้งหรือกระโดดในช่วงแรก ควบคู่กับการควบคุมอาหาร และเมื่อร่างกายแข็งแรงขึ้นและน้ำหนักเริ่มลดลง จึงค่อยปรับเพิ่มระดับความเข้มข้นของการออกกำลังกายต่อไปครับ"
   - *ผลประเมิน*: แบบจำลองวิเคราะห์ข้อมูลทางกายภาพ (น้ำหนักตัว 90 กิโลกรัม) ได้อย่างแม่นยำ โดยแนะนำประเภทการออกกำลังกายที่เลี่ยงแรงกระแทกเข่าเพื่อความปลอดภัยของผู้ใช้งาน

3) **กรณีทดสอบที่ 3: การตรวจจับลิงก์สแปมความปลอดภัย**
   - *คำถามผู้ใช้ (Prompt)*: "https://google.com"
   - *ผลประเมิน*: ระบบประมวลผลหลังบ้านสกัดและส่งกลับ HTTP 200 `OK URL` ทันทีโดยไม่ต้องยิงคำขอไปยัง Gemini API แสดงถึงระบบคัดกรองลิงก์และป้องกันสแปมที่มีประสิทธิภาพและความถูกต้อง 100%

4) **กรณีทดสอบที่ 4: การประมาณค่าแคลอรี่และสารอาหารจากรูปถ่ายอาหาร (Multimodal AI)**
   - *ข้อมูลนำเข้า (Input)*: รูปภาพจานอาหาร (เช่น รูปผัดกะเพราหมูสับไข่ดาวราดข้าว)
   - *คำตอบจาก AI (Reply)*: "ภาพถ่ายแสดงเมนูผัดกะเพราหมูสับไข่ดาวราดข้าว 1 จาน คาดการณ์ว่าให้พลังงานประมาณ 650 - 750 กิโลแคลอรี โดยมีส่วนประกอบหลักของคาร์โบไฮเดรตจากข้าวสวยประมาณ 60 กรัม, โปรตีนจากหมูสับและไข่ดาวประมาณ 25 กรัม, และไขมันจากการใช้น้ำมันผัดและทอดไข่ค่อนข้างสูงประมาณ 28 กรัม หากคุณกำลังควบคุมน้ำหนัก แนะนำให้รับประทานข้าวเพียงครึ่งจาน เลี่ยงการรับประทานไข่ดาวสุกในน้ำมันจัด หรือซับน้ำมันออก และเพิ่มผักใบเขียวในการบริโภคครับ"
   - *ผลประเมิน*: แบบจำลองประมวลผลและประมาณการค่าแคลอรี่จากรูปถ่ายจานอาหารได้อย่างแม่นยำ แยกแยะสัดส่วนสารอาหารหลักได้ชัดเจน และให้คำแนะนำโภชนาการที่เหมาะสมสั้นกระชับ
