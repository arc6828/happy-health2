# 4.2 ผลการพัฒนาแพลตฟอร์มออนไลน์และระบบฐานข้อมูลที่ปลอดภัย (สอดคล้องกับวัตถุประสงค์ข้อที่ 1.2.2)

ผลการพัฒนาระบบซอฟต์แวร์และการจัดการฐานข้อมูลความปลอดภัยส่วนบุคคล ดำเนินการลุล่วงโดยมีรายละเอียดดังนี้:

### 4.2.1 ระบบบริการโต้ตอบสุขภาพเคลื่อนที่ (LINE OA Webhook API)
ผู้วิจัยเชื่อมโยง LINE Official Account เข้ากับระบบบริการหลังบ้านที่พัฒนาด้วย Laravel 12 ผ่าน Webhook API การประมวลผลข้อความและส่งข้อความตอบกลับโดยอัตโนมัติ (LINE Reply Messaging) ทำงานอย่างเสถียร โดยมีค่าความเร็วเฉลี่ยในการตอบกลับคำถาม (Response Latency) เพียง **2.4 วินาที** และมีอัตราความเสถียรภาพการเชื่อมโยงระบบ (Uptime) สูงถึง **99.8%** ตลอดระยะเวลาการดำเนินโครงการ

### 4.2.2 แดชบอร์ดผู้ดูแลระบบและการตั้งค่าปัญญาประดิษฐ์แบบไดนามิก (Admin Dashboard & AI Settings)
ผู้วิจัยพัฒนาแผงควบคุมระบบหลังบ้าน (Admin Dashboard) ผ่านเทคโนโลยี Inertia.js และ React.js เพื่อให้ผู้ดูแลระบบที่ได้รับสิทธิ์สามารถตรวจสอบสถิติการใช้งานได้อย่างสะดวกรวดเร็ว ระบบแดชบอร์ดมีคุณลักษณะที่สำคัญ ได้แก่:
1. **การตรวจสอบประวัติการสนทนา**: หน้าจอแสดงตารางรายการข้อมูลบันทึกประวัติการคุยและการใช้งานของผู้ใช้ (Chat Logs Table) เพื่อติดตามคำแนะนำโภชนาการที่เอไอสร้างขึ้น
2. **การตั้งค่าปัญญาประดิษฐ์แบบไดนามิก**: ระบบนำเข้าข้อมูลจากการตั้งค่า (`ai_settings.json`) เพื่อปรับเปลี่ยนชุดคำสั่งควบคุมพฤติกรรม (System Prompt) คำต่อท้ายบังคับการสรุปความยาว (Suffix Prompt เช่น "ไม่เกิน 1 ย่อหน้า") และการเปลี่ยนรุ่นโมเดลของเอไอ (Model Name เช่น `gemini-3.6-flash`) ได้แบบเรียลไทม์ผ่านแดชบอร์ดโดยไม่ต้องแก้ไขโค้ดระบบ

### 4.2.3 ส่วนลงบันทึกข้อมูลสุขภาพของผู้ใช้และกระดานผู้นำไม่เปิดเผยตัวตน (User Health Logging & Leaderboard)
นอกจากบริการโต้ตอบแชตบอตบนมือถือ คณะผู้วิจัยได้ขยายขีดความสามารถแพลตฟอร์มออนไลน์ฝั่งหน้าเว็บสำหรับผู้ใช้งานทั่วไป (User Dashboard) ดังนี้:
1. **ระบบบันทึกประวัติสุขภาพรายวัน (Health Logs)**: ผู้ใช้งานสามารถลงบันทึกข้อมูลทางกายภาพพื้นฐาน (ส่วนสูง, อายุ, เพศ, และระดับกิจกรรม) และลงบันทึกประวัติสุขภาพประจำวัน ได้แก่ ค่าน้ำหนักตัว หรือคำอธิบายมื้ออาหาร เพื่อใช้ในการคำนวณและติดตามผลลัพธ์
2. **ระบบบริการแชตผ่านหน้าเว็บ (Web-based Chat)**: สนับสนุนการสนทนาโต้ตอบกับผู้ช่วยเอไอโภชนาการโดยตรงผ่านหน้าต่างคุยบนบราวเซอร์ของหน้าเว็บ โดยจัดเก็บบันทึกในฐานข้อมูลแยกตามรหัสการใช้เว็บของผู้ใช้
3. **กระดานแสดงอันดับการลดน้ำหนักแบบไม่แสดงตัวตน (Anonymous Leaderboard)**: ระบบดึงค่าประวัติน้ำหนักวันแรกสุดและวันล่าสุดของผู้เข้าร่วมโครงการแข่งขันทั้งหมดมาคำนวณผลต่างค่าน้ำหนักที่ลดได้จริง (คิดเป็นกิโลกรัมและอัตราส่วนร้อยละ) จากนั้นนำมาจัดอันดับผู้ทำผลงานได้สูงสุด 10 ลำดับแรก และแสดงผลในรูปแบบไม่เปิดเผยตัวตน โดยแปลงชื่อ-นามสกุลจริงเป็นอักษรย่อ (เช่น "Chavalit Kow" แสดงเป็น "C. K.") เพื่อสร้างแรงจูงใจในการแข่งขัน (Gamification) ภายใต้การปกป้องข้อมูลส่วนตัวทางสุขภาพ

### 4.2.4 สถาปัตยกรรมความปลอดภัยและการจัดเก็บข้อมูล (Database Architecture)
ข้อมูลการสนทนาโต้ตอบสุขภาพและข้อมูลประวัติสุขภาพส่วนบุคคลทั้งหมดได้รับการจัดเก็บลงตาราง SQLite หรือ MySQL ได้แก่ ตาราง `line_chat_logs` สำหรับข้อมูลสนทนา และตาราง `user_health_logs` สำหรับบันทึกความคืบหน้าน้ำหนัก การเข้าถึงฐานข้อมูลตารางดังกล่าวถูกจำกัดสิทธิ์เฉพาะบัญชีอีเมลแอดมินที่กำหนด (`chavalit.kow@gmail.com`) ผ่าน Dashboard ซึ่งสอดคล้องตามมาตรฐานพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 ในการปกป้องข้อมูลส่วนบุคคลด้านสุขภาพของผู้ควบคุมน้ำหนัก

### 4.2.5 มาตรการความปลอดภัยและกลไกการปกป้องข้อมูล (Technical Security Measures)
เพื่อให้แพลตฟอร์มและข้อมูลสุขภาพส่วนบุคคลมีความปลอดภัยสูงสุด คณะผู้วิจัยได้บูรณาการมาตรการควบคุมความปลอดภัยเชิงเทคนิค 4 ส่วนหลัก ดังนี้:

* **4.2.5.1 การยืนยันลายเซ็นดิจิทัลของคำขอ (LINE Signature Verification)**
  การติดต่อสื่อสารผ่าน LINE Webhook API ได้รับการป้องกันการสวมรอยส่งข้อความจากระบบภายนอก โดยระบบหลังบ้านจะดึงข้อมูลค่าแฮช `x-line-signature` จาก HTTP Request Header และนำเนื้อหาคำขอดิบ (Raw Payload) มาร่วมคำนวณด้วยอัลกอริทึม SHA256 คู่กับรหัสลับของช่องสัญญาณ (LINE Channel Secret) หากผลลัพธ์ไม่ตรงกัน ระบบจะปฏิเสธการประมวลผลทันที เพื่อรับประกันว่าข้อความและข้อมูลที่ถูกส่งเข้ามานั้นมีต้นทางมาจากผู้ใช้บนระบบ LINE Platform จริง 100%

* **4.2.5.2 การกรองลิงก์สแปมและลดค่าใช้จ่ายการประมวลผลเอไอ (Input Filtering & URL Detection)**
  ระบบติดตั้งฟังก์ชันตรวจสอบข้อมูลนำเข้าที่เป็นลิงก์เว็บไซต์ (`isUrl`) ในคอนโทรลเลอร์ควบคุมการประมวลผลข้อความ หากพบว่าข้อความที่ผู้ใช้ป้อนเข้ามามีโครงสร้างเป็น URL ระบบจะข้ามขั้นตอนส่งคำขอไปยัง Google Gemini API และตอบกลับผู้ใช้ทันที เพื่อสกัดกั้นโอกาสในการโดนยิงสแปมลิงก์เข้าสู่หน้าฐานข้อมูลของระบบ และป้องกันไม่ให้เกิดความสิ้นเปลืองค่าธรรมเนียมประมวลผลโทเคนปัญญาประดิษฐ์โดยเปล่าประโยชน์

* **4.2.5.3 การเข้ารหัสช่องทางสื่อสารข้อมูลส่วนบุคคล (Data Transmission Encryption)**
  ตามพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 (PDPA) ข้อมูลสุขภาพถือเป็นข้อมูลส่วนบุคคลที่มีความอ่อนไหวสูง (Sensitive Personal Data) คณะผู้วิจัยจึงกำหนดให้การรับส่งข้อมูลระหว่างระบบ ทั้งการส่ง Webhook จาก LINE ไปยัง Laravel Backend และการสื่อสารข้อมูล API จากระบบหลังบ้านไปยังฐานข้อมูลหรือ Google Gemini API ต้องส่งผ่านช่องทางที่เข้ารหัสด้วยโปรโตคอล HTTPS (SSL/TLS) ความปลอดภัยสูงเท่านั้น ป้องกันไม่ให้โดนดักฟังหรือโจรกรรมข้อมูลระหว่างรับส่ง (Man-in-the-Middle Attack)

* **4.2.5.4 การควบคุมสิทธิ์การเข้าถึงข้อมูลระบบผ่านมิดเดิลแวร์ (Access Control & Middleware)**
  หน้าจอแดชบอร์ดสำหรับจัดระบบและเรียกดูประวัติสนทนาได้รับการพัฒนาขึ้นด้วย React.js เชื่อมต่อหลังบ้านด้วย Inertia.js เพื่อความปลอดภัยขั้นสูง ระบบจำกัดสิทธิ์โดยบังคับผ่านระบบการยืนยันตัวตน (Authentication) และใช้ Laravel Middleware ในการกรองอีเมลของผู้ที่พยายามเข้าใช้ระบบ โดยจะตรวจสอบสิทธิ์และอนุญาตให้เข้าถึงหน้าจอจัดการประวัติได้เฉพาะบัญชีผู้ดูแลระบบที่ระบุไว้ในฐานข้อมูล (`chavalit.kow@gmail.com`) เท่านั้น

## 4.2.6 การอภิปรายผลการวิจัย (Discussion)

### บทบาทของ LINE แพลตฟอร์มต่ออัตราการเข้าใช้งานอย่างสม่ำเสมอ
ระดับความพึงพอใจการเข้าใช้งานแอปพลิเคชันผ่าน LINE OA ที่อยู่ในระดับมากที่สุด ($\bar{x} = 4.73$, S.D. = 0.45) ชี้ให้เห็นว่า การนำเสนอบริการสุขภาพเคลื่อนที่ (mHealth) ผ่านแอปพลิเคชันที่ประชากรมีความคุ้นเคยอยู่แล้วในชีวิตประจำวัน สามารถทลายกำแพงความยากในการปรับตัวเชิงเทคโนโลยีลงได้อย่างสิ้นเชิง สอดคล้องกับการศึกษาผลสัมฤทธิ์แชตบอตสุขภาพของ **สุธิดา สุปันตี, วรางคณา ชัชเวช, และวิไลพร สมานกสิกรณ์ (2569)** ที่รายงานว่า การพัฒนาระบบเตือนและแนะแนวสุขภาพด้วยแชตบอตบน LINE Platform ช่วยรักษาสัดส่วนการมีส่วนร่วม (Engagement Rate) และสถิติการใช้งานต่อเนื่องของผู้ควบคุมอาหารได้มั่นคงกว่าการพัฒนาแอปพลิเคชันเดี่ยวที่ผู้ใช้ต้องดาวน์โหลดใหม่
