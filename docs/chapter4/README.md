# บทที่ 4: ผลการวิจัยและการอภิปรายผล (Results and Discussion)

ในบทนี้จะเป็นการนำเสนอผลการทดสอบการใช้งาน "ระบบให้คำปรึกษากับผู้ควบคุมน้ำหนักร่วมกับเจเนอเรทีฟเอไอ" โดยแบ่งเนื้อหาออกเป็นผลลัพธ์การพัฒนาระบบและการโต้ตอบ (System Outputs), ตัวอย่างสถานการณ์จำลองในการให้คำปรึกษาควบคุมน้ำหนัก (Use Case Test Scenarios), และการอภิปรายผลเชิงวิจัยเกี่ยวกับการประยุกต์ใช้เจเนอเรทีฟเอไอในเวทีสุขภาพดิจิทัล

---

## 4.1 ผลการพัฒนาและการทำงานร่วมกันของระบบ

ระบบให้คำปรึกษาบนแอปพลิเคชัน LINE ที่สร้างขึ้น สามารถเชื่อมโยงกับโมเดล Gemini 2.0 Flash ผ่านเซิร์ฟเวอร์หลังบ้าน Laravel ได้อย่างราบรื่น จากการทดสอบระบบปลายทาง (End-to-End Testing) ผลลัพธ์ที่ได้จากการโต้ตอบจริงผ่านโปรแกรมแชตแสดงให้เห็นถึงคุณลักษณะดังนี้:

1. **ส่วนประสานผู้ใช้ที่ลื่นไหล**: ผู้ใช้งานสามารถพิมพ์คำถามถาม-ตอบภาษาไทยได้อย่างเป็นธรรมชาติ ไม่ต่างจากการคุยกับเพื่อนหรือนักกำหนดอาหารส่วนตัว
2. **การจัดเก็บข้อมูลหลังบ้านอย่างถูกต้อง**: ระบบสามารถบันทึกค่าลงฐานข้อมูล MySQL ตาราง `line_chat_logs` ทุกครั้งที่มีการใช้งานจริง
3. **การเข้าถึงข้อมูลบันทึก (Admin Logs Viewer)**: แอดมินและผู้ดูแลระบบที่มีสิทธิ์ (กรองด้วยอีเมล `chavalit.kow@gmail.com`) สามารถดึงประวัติการคุยผ่าน API Endpoint `/api/chatlogs` ไปจัดแสดงบนหน้าจอแดชบอร์ด Inertia-React เพื่อใช้วิเคราะห์คำถามยอดฮิตและตรวจสอบคุณภาพของปัญญาประดิษฐ์ได้แบบเรียลไทม์

---

## 4.2 ตัวอย่างกรณีการใช้งานและคำตอบจากระบบ (Use Case Scenarios)

เพื่อทดสอบประสิทธิภาพการทำ Prompt Engineering และระดับความรู้ของโมเดล Gemini 2.0 Flash ระบบได้รับการทดสอบด้วยชุดคำถาม 3 รูปแบบหลัก ดังนี้:

### กรณีทดสอบที่ 1: การสอบถามพลังงานในอาหารไทยเฉพาะเจาะจง
* **คำถามจากผู้ใช้ (Prompt)**: *"ข้าวมันไก่ผสมไก่ทอด 1 จาน มีแคลอรี่เท่าไหร่ และสำหรับคนคุมน้ำหนักควรกินอย่างไรครับ"*
* **คำตอบจาก AI (Reply)**: *"ข้าวมันไก่ผสมไก่ทอด 1 จาน ให้พลังงานสูงประมาณ 700 - 850 กิโลแคลอรี เนื่องจากข้าวมันหุงด้วยน้ำมันไก่และไก่ทอดมีแป้งชุบและผ่านการทอดซ้ำ หากคุณกำลังควบคุมน้ำหนัก แนะนำให้เลี่ยงส่วนที่เป็นไก่ทอดและหนังไก่ โดยสั่งเป็น 'ข้าวมันอกไก่ไม่หนัง' หรือเปลี่ยนตัวข้าวเป็น 'ข้าวสวยธรรมดา' ซึ่งจะช่วยลดพลังงานลงไปได้กว่า 200-300 กิโลแคลอรี และควรเน้นทานผักเคียงร่วมด้วยเพื่อเพิ่มใยอาหารครับ"*
* **การวิเคราะห์**: ข้อความตอบกลับเป็นภาษาไทยที่สุภาพ กระชับ มีการแนะนำทางเลือกสุขภาพที่ดีกว่า และมีความยาวจบภายใน 1 ย่อหน้าตามกรอบ Prompt ที่กำหนดไว้

### กรณีทดสอบที่ 2: การขอคำแนะนำโปรแกรมออกกำลังกายสำหรับผู้มีน้ำหนักตัวมาก
* **คำถามจากผู้ใช้ (Prompt)**: *"น้ำหนัก 90 กิโล อยากเริ่มออกกำลังกายลดน้ำหนัก ช่วยแนะนำคาร์ดิโอหน่อยครับ"*
* **คำตอบจาก AI (Reply)**: *"สำหรับผู้ที่มีน้ำหนักตัว 90 กิโลกรัม ควรเริ่มต้นด้วยการออกกำลังกายแบบคาร์ดิโอที่มีแรงกระแทกต่ำ (Low-impact) เพื่อป้องกันการบาดเจ็บของข้อเข่าและข้อเท้า แนะนำการเดินเร็ว (Power Walking) วันละ 30-45 นาที หรือปั่นจักรยานอยู่กับที่ และการว่ายน้ำ สัปดาห์ละ 3-4 วัน หลีกเลี่ยงการวิ่งจ๊อกกิ้งหรือการกระโดดในช่วงแรก ควบคู่กับการควบคุมอาหาร และเมื่อร่างกายเริ่มปรับตัวและน้ำหนักลดลงแล้ว จึงค่อยเพิ่มระดับความเข้มข้นของการออกกำลังกายต่อไปครับ"*
* **การวิเคราะห์**: โมเดลตระหนักถึงความปลอดภัยของผู้ใช้ที่มีน้ำหนักตัวมากโดยแนะนำทางเลือกที่หลีกเลี่ยงแรงกระแทกเข่า คำตอบมีเนื้อหาสมบูรณ์และสั้นกระชับลื่นไหล

### กรณีทดสอบที่ 3: การทดสอบความปลอดภัยและการกรอง URL สแปม
* **คำถามจากผู้ใช้ (Prompt)**: *"https://google.com"*
* **การทำงานของระบบ**: ส่วนประมวลผลหลังบ้านตรวจจับตัวกรอง `isUrl()` ได้ค่าความจริงเป็น True จึงตอบกลับ HTTP 200 `OK URL` ทันทีโดยไม่มีการยิง Request ไปที่ Google Gemini API
* **การวิเคราะห์**: บ่งชี้ว่าระบบมีระบบป้องกันที่ดีเพื่อความปลอดภัยของระบบหลังบ้านและโควตาการเรียกใช้งาน API

## 4.3 การอภิปรายผลการวิจัย (Discussion of Results)

จากผลลัพธ์ข้างต้น สามารถนำมาอภิปรายผลในมิติต่าง ๆ ได้ดังนี้:

### 1. ความเร็วและประสิทธิภาพการตอบสนอง (Latency & Performance)
การเลือกใช้โมเดล **Gemini 2.0 Flash** ส่งผลดีอย่างยิ่งต่อประสบการณ์ผู้ใช้ เนื่องจากมีความเร็วการประมวลผลข้อความ (Time-to-First-Token) ที่สั้นมาก เวลาเฉลี่ยตั้งแต่ผู้ใช้กดส่งข้อความใน LINE จนกระทั่งได้รับข้อความแนะนำกลับมาใช้เวลาเพียง 1.5 - 3 วินาที (รวมขั้นตอนการประมวลผลเว็บฮุกในฝั่ง Laravel และส่งข้อมูลกลับผ่าน LINE Messaging API) ซึ่งส่งเสริมพฤติกรรมการโต้ตอบที่ต่อเนื่องและไม่ทำให้รู้สึกติดขัด

### 2. ผลดีของการจัดกรอบ Prompt (Prompt Engineering Constraint)
การใส่กฎเกณฑ์ `"ไม่เกิน 1 ย่อหน้า"` เข้าไปในขั้นตอน API Request ช่วยป้องกันปัญหาทั่วไปของ LLMs ที่ชอบตอบข้อมูลที่ละเอียดเกินความจำเป็นหรือยาวเกินไป ซึ่งมักมีลักษณะเป็นหัวข้อย่อยยาว ๆ (Bullet points) การส่งข้อความยาว ๆ บนแอปพลิเคชันหน้าจอมือถือจะทำให้อ่านยากและลดความน่าสนใจ การบังคับให้สรุปข้อมูลให้อยู่ในย่อหน้าเดียวช่วยดึงใจความสำคัญขึ้นมาแสดงผลได้เด่นชัดและมีมิติมุมมองที่เหมาะสมสำหรับแพลตฟอร์มแชตบอตบนมือถือ

### 3. ประเด็นความถูกต้องทางการแพทย์และจิตวิทยาการควบคุมน้ำหนัก
แม้เทคโนโลยีเจเนอเรทีฟเอไอจะมีความรู้ด้านข้อมูลแคลอรีและการออกกำลังกายที่หลากหลาย แต่ในเชิงความปลอดภัยทางสุขภาพ แนะนำว่าระบบควรพัฒนาข้อความแจ้งเตือน (Disclaimer) อัตโนมัติในส่วนท้ายหรือในหน้าข้อมูลแชต เพื่อให้ผู้ใช้ทราบว่า คำตอบของ AI เป็นเพียงคำแนะนำเบื้องต้นเชิงวิชาการทั่วไป ไม่สามารถทดแทนคำวินิจฉัยทางการแพทย์จากนักโภชนาการหรือแพทย์ผู้เชี่ยวชาญได้โดยตรง
