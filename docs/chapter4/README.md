# บทที่ 4: ผลการวิจัยและการอภิปรายผล (Results and Discussion)

ที่อยู่เว็บไซต์อย่างเป็นทางการของโครงการ: **[https://happyhealthhappyheart.com](https://happyhealthhappyheart.com)**

ในบทนี้เป็นการนำเสนอผลการวิจัยและการอภิปรายผลจากการศึกษา พัฒนา และทดสอบระบบให้คำปรึกษากับผู้ควบคุมน้ำหนักร่วมกับเจเนอเรทีฟเอไอ (Google Gemini 3.6 Flash) คณะผู้วิจัยได้จัดแบ่งหัวข้อรายงานผลการวิจัยออกเป็น 4 ส่วนหลักตามวัตถุประสงค์ของการวิจัยในบทที่ 1 โดยมีสารบัญและบทสรุปผลการดำเนินงานจำแนกตามเอกสารแต่ละฉบับดังนี้:

---

## สารบัญรายงานผลการวิจัยตามวัตถุประสงค์

1) [**4.1 ผลการวิเคราะห์ ออกแบบ และพัฒนาแบบจำลอง AI สำหรับการให้คำปรึกษา** (สอดคล้องกับวัตถุประสงค์ข้อที่ 1.2.1)](objective1.md)
   การพัฒนาแบบจำลอง Gemini 3.6 Flash ร่วมกับกลไก Personalized Context Injection และ Multimodal AI สแกนวิเคราะห์ภาพถ่ายจานอาหาร โดยมีผลสัมฤทธิ์คือความตรงเชิงเนื้อหาถูกต้องตามหลักโภชนาการ ป้องกันลิงก์สแปม 100% และตอบกระชับจบภายใน 1 ย่อหน้า

2) [**4.2 ผลการพัฒนาแพลตฟอร์มออนไลน์และระบบฐานข้อมูลที่ปลอดภัย** (สอดคล้องกับวัตถุประสงค์ข้อที่ 1.2.2)](objective2.md)
   สถาปัตยกรรมระบบเว็บหลังบ้าน Laravel 12, LINE Webhook API, แดชบอร์ดแอดมิน (Admin Dashboard), กระดานผู้นำ (Leaderboard) และมาตรการความปลอดภัยตามมาตรฐาน PDPA โดยมีความเร็วในการตอบกลับเฉลี่ย 2.4 วินาที ความเสถียรภาพระบบ (Uptime) สูงถึง 99.8% และปกป้องข้อมูลส่วนบุคคลตาม พ.ร.บ. คุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562

3) [**4.3 ผลการอบรม สนับสนุนความรู้ และแนะแนวโภชนาการเฉพาะบุคคล** (สอดคล้องกับวัตถุประสงค์ข้อที่ 1.2.3)](objective3.md)
   การจัดกิจกรรมอบรมเชิงปฏิบัติการ (Workshop) ถ่ายทอดเทคโนโลยี และการเผยแพร่คลังบทความความรู้ผ่านบล็อกสาธารณะ Medium โดยความพึงพอใจต่อระบบแอปพลิเคชันและการแนะแนวสุขภาพอยู่ในเกณฑ์มากที่สุด ($\bar{x} = 4.59$, S.D. = 0.49) และความพึงพอใจต่อการจัดกิจกรรมอบรมอยู่ในเกณฑ์มากที่สุด ($\bar{x} = 4.62$, S.D. = 0.50)

4) [**4.4 ผลการจัดการแข่งขันการลดน้ำหนักและการวิเคราะห์ผลลัพธ์สุขภาพเชิงตัวเลข** (สอดคล้องกับวัตถุประสงค์ข้อที่ 1.2.4)](objective4.md)
   การจัดการแข่งขันลดน้ำหนัก 8 สัปดาห์ร่วมกับการวัดผลเชิงการแพทย์ในกลุ่มตัวอย่าง $n = 38$ ราย พบว่าน้ำหนักตัวลดลงเฉลี่ย 1.69 กิโลกรัม ($p < .001$), BMI ลดลง 0.63 $\text{kg/m}^2$ ($p < .001$), เปอร์เซ็นต์ไขมันลดลง 1.36% ($p < .001$), มวลกล้ามเนื้อเพิ่มขึ้น 0.70 กิโลกรัม ($p = .017$), ความรู้ 3 อ. เพิ่มขึ้น 2.18 คะแนน ($p < .001$) และพฤติกรรมสุขภาพรวมเพิ่มขึ้น 0.70 คะแนน ($p < .001$)
