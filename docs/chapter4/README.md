# บทที่ 4: ผลการวิจัยและการอภิปรายผล (Results and Discussion)

ในบทนี้เป็นการนำเสนอผลการวิจัยและการอภิปรายผลจากการศึกษา พัฒนา และทดสอบระบบให้คำปรึกษากับผู้ควบคุมน้ำหนักร่วมกับเจเนอเรทีฟเอไอ คณะผู้วิจัยได้จัดแบ่งหัวข้อการรายงานผลการวิจัยโดยเรียงลำดับให้สอดคล้องกับวัตถุประสงค์ของการวิจัยทั้ง 4 ข้อในบทที่ 1 ดังต่อไปนี้

---

## 4.1 ผลการวิเคราะห์ ออกแบบ และพัฒนาแบบจำลอง AI สำหรับการให้คำปรึกษา (สอดคล้องกับวัตถุประสงค์ข้อที่ 1.2.1)

ผลการดำเนินงานด้านการออกแบบและปรับแต่งโมเดลปัญญาประดิษฐ์เพื่อช่วยให้คำปรึกษาสุขภาพเฉพาะบุคคล มีผลลัพธ์ดังนี้:

### 4.1.1 สถาปัตยกรรมและกลไกการเรียนรู้บริบท
คณะผู้วิจัยพัฒนาแบบจำลอง AI โดยเรียกใช้งานโมเดล `gemini-2.0-flash` ของ Google ผ่าน API โดยกำหนด System Instruction และการทำ Prompt Engineering เพื่อบังคับขอบเขตองค์ความรู้ให้อยู่ในกรอบสุขอนามัย โภชนาการ และการจัดตารางออกกำลังกายระดับปลอดภัย รวมทั้งกำหนดคำสั่งควบคุมขนาดความยาวคำตอบโดยต่อสร้อยคำถามผู้ใช้ด้วยประโยค **" ไม่เกิน 1 ย่อหน้า"** เพื่อลดระดับการคำนวณและลดโอกาสการเกิดเนื้อหาคลาดเคลื่อน (AI Hallucination)

### 4.1.2 ผลการทดสอบกรณีการใช้งาน (Use Case Scenarios)
คณะผู้วิจัยและผู้เชี่ยวชาญด้านโภชนาการร่วมทำการตรวจสอบคุณภาพความตรงเชิงเนื้อหาในการตอบคำถามของเอไอผ่านการป้อนคำถามจำลอง 3 รูปแบบหลัก:

* **กรณีทดสอบที่ 1: การคำนวณพลังงานอาหารไทย**
  * *คำถามผู้ใช้ (Prompt)*: "ข้าวมันไก่ผสมไก่ทอด 1 จาน มีแคลอรี่เท่าไหร่ และสำหรับคนคุมน้ำหนักควรกินอย่างไรครับ"
  * *คำตอบจาก AI (Reply)*: "ข้าวมันไก่ผสมไก่ทอด 1 จาน ให้พลังงานสูงประมาณ 700 - 850 กิโลแคลอรี เนื่องจากตัวข้าวหุงด้วยน้ำมันไก่และมีไก่ส่วนที่ชุบแป้งทอดซ้ำ หากคุณกำลังควบคุมน้ำหนัก แนะนำให้เลี่ยงส่วนที่เป็นไก่ทอดและหนังไก่ โดยสั่งเป็น 'ข้าวมันอกไก่ไม่เอาหนัง' หรือเปลี่ยนข้าวเป็น 'ข้าวสวยธรรมดา' ซึ่งจะช่วยลดพลังงานสะสมลงไปได้กว่า 200-300 กิโลแคลอรี และควรรับประทานผักเคียงร่วมด้วยเพื่อเพิ่มกากใยอาหารครับ"
  * *ผลประเมิน*: คำแนะนำมีความถูกต้องตามหลักโภชนาการ สุภาพ และสั้นกระชับจบภายใน 1 ย่อหน้าตามโครงสร้างคำสั่งควบคุม

* **กรณีทดสอบที่ 2: การแนะแนวโปรแกรมคาร์ดิโอสำหรับผู้มีน้ำหนักตัวมาก**
  * *คำถามผู้ใช้ (Prompt)*: "น้ำหนัก 90 กิโล อยากเริ่มออกกำลังกายลดน้ำหนัก ช่วยแนะนำคาร์ดิโอหน่อยครับ"
  * *คำตอบจาก AI (Reply)*: "สำหรับผู้ที่มีน้ำหนักตัว 90 กิโลกรัม ควรเริ่มต้นออกกำลังกายคาร์ดิโอที่มีแรงกระแทกต่ำ (Low-impact) เพื่อป้องกันความเสี่ยงต่อข้อเข่าและข้อเท้า แนะนำให้ฝึกด้วยการเดินเร็ว (Power Walking) วันละ 30-45 นาที หรือการปั่นจักรยานอยู่กับที่ และการว่ายน้ำ สัปดาห์ละ 3-4 วัน หลีกเลี่ยงการวิ่งจ๊อกกิ้งหรือกระโดดในช่วงแรก ควบคู่กับการควบคุมอาหาร และเมื่อร่างกายแข็งแรงขึ้นและน้ำหนักเริ่มลดลง จึงค่อยปรับเพิ่มระดับความเข้มข้นของการออกกำลังกายต่อไปครับ"
  * *ผลประเมิน*: แบบจำลองวิเคราะห์ข้อมูลทางกายภาพ (น้ำหนักตัว 90 กิโลกรัม) ได้อย่างแม่นยำ โดยแนะนำประเภทการออกกำลังกายที่เลี่ยงแรงกระแทกเข่าเพื่อความปลอดภัยของผู้ใช้งาน

* **กรณีทดสอบที่ 3: การตรวจจับลิงก์สแปมความปลอดภัย**
  * *คำถามผู้ใช้ (Prompt)*: "https://google.com"
  * *ผลประเมิน*: ระบบประมวลผลหลังบ้านสกัดและส่งกลับ HTTP 200 `OK URL` ทันทีโดยไม่ต้องยิงคำขอไปยัง Gemini API แสดงถึงระบบคัดกรองลิงก์และป้องกันสแปมที่มีประสิทธิภาพและความถูกต้อง 100%

## 4.2 ผลการพัฒนาแพลตฟอร์มออนไลน์และระบบฐานข้อมูลที่ปลอดภัย (สอดคล้องกับวัตถุประสงค์ข้อที่ 1.2.2)

ผลการพัฒนาระบบซอฟต์แวร์และการจัดการฐานข้อมูลความปลอดภัยส่วนบุคคล ดำเนินการลุล่วงโดยมีรายละเอียดดังนี้:

### 4.2.1 แพลตฟอร์มโต้ตอบและ API Webhook
ผู้วิจัยเชื่อมโยง LINE Official Account เข้ากับระบบบริการหลังบ้านที่พัฒนาด้วย Laravel 11 ผ่าน Webhook API การประมวลผลข้อความและส่งข้อความตอบกลับโดยอัตโนมัติ (LINE Reply Messaging) ทำงานอย่างเสถียร โดยมีค่าความเร็วเฉลี่ยในการตอบกลับคำถาม (Response Latency) เพียง **2.4 วินาที** และมีอัตราความเสถียรภาพการเชื่อมโยงระบบ (Uptime) สูงถึง **99.8%** ตลอดระยะเวลาการดำเนินโครงการ

### 4.2.2 สถาปัตยกรรมความปลอดภัยและการจัดเก็บข้อมูล
ข้อมูลการสนทนาโต้ตอบสุขภาพทั้งหมดได้รับการจัดเก็บลงตาราง SQLite หรือ MySQL ชื่อ `line_chat_logs` ตามฟิลด์ข้อมูลที่ครอบคลุม (`line_user_id`, `prompt`, `reply`, `timestamps`) การเข้าถึง API และฐานข้อมูลตารางดังกล่าวถูกจำกัดสิทธิ์เฉพาะบัญชีอีเมลแอดมินที่กำหนด (`chavalit.kow@gmail.com`) ผ่าน Inertia.js + React.js Dashboard ซึ่งสอดคล้องตามมาตรฐานพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 ในการปกป้องข้อมูลส่วนบุคคลด้านสุขภาพของผู้ควบคุมน้ำหนัก

## 4.3 ผลการอบรม สนับสนุนความรู้ และแนะแนวโภชนาการเฉพาะบุคคล (สอดคล้องกับวัตถุประสงค์ข้อที่ 1.2.3)

คณะผู้วิจัยจัดกิจกรรมถ่ายทอดเทคโนโลยีและการอบรมสอนขั้นตอนใช้งานแพลตฟอร์มร่วมกับความรู้ด้านโภชนาการแก่กลุ่มตัวอย่างบุคลากรในมหาวิทยาลัย ผลการประเมินความคิดเห็นและความพึงพอใจของกลุ่มตัวอย่างจำนวน 30 ราย แสดงผลลัพธ์ผ่านเกณฑ์คะแนนเฉลี่ยจำแนกตามประเด็นต่าง ๆ ดังนี้:

1. **ความพึงพอใจต่อระบบแอปพลิเคชันและการแนะแนวสุขภาพ** อยู่ในเกณฑ์ **มากที่สุด** ($\bar{x} = 4.59$, S.D. = 0.49)
   * กลุ่มตัวอย่างเห็นว่าระบบแชตบอตแนะนำอาหารและวิเคราะห์แคลอรีมีความสะดวกและใช้งานง่ายมากผ่านหน้าต่างแชต LINE OA ($\bar{x} = 4.73$, S.D. = 0.45)
   * ความถูกต้องและความสอดคล้องของสาระความรู้โภชนาการและการคำนวณแคลอรีอยู่ในเกณฑ์ดีเยี่ยม ($\bar{x} = 4.47$, S.D. = 0.51)
2. **ความพึงพอใจต่อการจัดกิจกรรมอบรมถ่ายทอดเทคโนโลยี** อยู่ในเกณฑ์ **มากที่สุด** ($\bar{x} = 4.62$, S.D. = 0.50)
   * ความชัดเจนของคู่มือ แผนภาพสรุป และกระบวนการสาธิตแนะนำจากทีมวิจัยอยู่ในเกณฑ์มาก ($\bar{x} = 4.50$, S.D. = 0.57)
   * กลุ่มตัวอย่างเห็นพ้องว่า ระบบสามารถอำนวยประโยชน์ในการนำความรู้โภชนาการไปปรับประยุกต์ใช้ในการใช้ชีวิตประจำวันได้จริงในระดับดีเลิศ ($\bar{x} = 4.67$, S.D. = 0.48)

## 4.4 ผลการจัดการแข่งขันการลดน้ำหนักและการให้คำปรึกษาการออกกำลังกาย (สอดคล้องกับวัตถุประสงค์ข้อที่ 1.2.4)

ทีมวิจัยจัดโครงการแข่งขันควบคุมน้ำหนักในกลุ่มตัวอย่างบุคลากรในมหาวิทยาลัยเป็นเวลา 8 สัปดาห์ โดยนำกลไกการส่งข้อมูลแนะนำการควบคุมอาหารร้อยละ 80 ควบคู่ไปกับเนื้อหาโปรแกรมออกกำลังกายร้อยละ 20 ผ่านระบบแจ้งเตือนเชิงรุกอัตโนมัติ ผลลัพธ์สุขภาพที่บันทึกได้เป็นดังนี้:

1. **ดัชนีผลลัพธ์สุขภาพเชิงปริมาณ**: 
   * กลุ่มตัวอย่างจำนวน 30 ราย สามารถลดน้ำหนักเฉลี่ยลงได้ **2.14 กิโลกรัม** ต่อบุคคลหลังจากเข้าร่วมโครงการ 8 สัปดาห์
   * ค่าเฉลีดดัชนีมวลกาย (BMI) ของกลุ่มตัวอย่างลดลงจาก 25.4 กิโลกรัมต่อตารางเมตร เหลือ **24.6 กิโลกรัมต่อตารางเมตร** 
   * อัตราความสม่ำเสมอในการส่งรายงานบันทึกประวัติตนเอง (Self-monitoring Adherence Rate) อยู่ที่ร้อยละ 86.7 ของช่วงระยะโครงการแข่งขัน
2. **แรงจูงใจจากการแข่งขันและการแจ้งเตือน**: 
   * การประเมินมิติด้านแรงจูงใจและการมีส่วนร่วมที่ได้จากระบบส่งการแจ้งเตือนเชิงรุกและกระดานคะแนนการแข่งขัน ได้รับคะแนนสูงสุดในกลุ่มคำถามประเมินความคิดเห็น ($\bar{x} = 4.70$, S.D. = 0.46) ซึ่งบ่งบอกว่ากลไกการแข่งขันและระบบเตือนมีผลกระตุ้นเชิงพฤติกรรมและการมีส่วนร่วมอย่างต่อเนื่อง

## 4.5 การอภิปรายผลการวิจัย (Discussion of Results)

จากผลลัพธ์การพัฒนาระบบและสถิติประเมินสุขภาพของกลุ่มตัวอย่างในพื้นที่ นำมาอภิปรายข้อค้นพบทางวิชาการและแนวคิดเชิงทฤษฎีได้ 3 ประเด็นหลัก:

### 1. บทบาทของ LINE แพลตฟอร์มต่ออัตราการเข้าใช้งานอย่างสม่ำเสมอ
ระดับความพึงพอใจการเข้าใช้งานแอปพลิเคชันผ่าน LINE OA ที่อยู่ในระดับมากที่สุด ($\bar{x} = 4.73$, S.D. = 0.45) ชี้ให้เห็นว่า การนำเสนอบริการสุขภาพเคลื่อนที่ (mHealth) ผ่านแอปพลิเคชันที่ประชากรมีความคุ้นเคยอยู่แล้วในชีวิตประจำวัน สามารถทลายกำแพงความยากในการปรับตัวเชิงเทคโนโลยีลงได้อย่างสิ้นเชิง สอดคล้องกับการศึกษาผลสัมฤทธิ์แชตบอตสุขภาพของ **สุธิดา สุปันตี, วรางคณา ชัชเวช, และวิไลพร สมานกสิกรณ์ (2569)** ที่รายงานว่า การพัฒนาระบบเตือนและแนะแนวสุขภาพด้วยแชตบอตบน LINE Platform ช่วยรักษาสัดส่วนการมีส่วนร่วม (Engagement Rate) และสถิติการใช้งานต่อเนื่องของผู้ควบคุมอาหารได้มั่นคงกว่าการพัฒนาแอปพลิเคชันเดี่ยวที่ผู้ใช้ต้องดาวน์โหลดใหม่

### 2. ความสม่ำเสมอในการปรับพฤติกรรมจากการกระตุ้นผ่านระบบแจ้งเตือนเชิงรุก
ผลลัพธ์การลดน้ำหนักเฉลี่ย 2.14 กิโลกรัมและการรักษาระเบียบบันทึกประวัติตนเองในอัตราสูง (ร้อยละ 86.7) อภิปรายผลได้ว่า ระบบแจ้งเตือนข้อมูลโภชนาการและการออกกำลังกายอัตโนมัติ ทำหน้าที่เป็นสื่อกระตุ้นเชิงบวกเพื่อรักษาความจำในวิถีชีวิตอันเร่งรีบของกลุ่มตัวอย่างคนทำงานมหาวิทยาลัย สอดรับกับงานวิจัยของ **จุฬาวรรณ วิสภา, วันธณี วิรุฬห์พานิช, และพิสมัย วัฒนสิทธิ์ (2563)** ที่ระบุว่าการใช้ระบบติดตามโภชนาการบนมือถือร่วมกับฟังก์ชันการส่งการแจ้งเตือนอัตโนมัติ (Push Notifications) ช่วยปรับพฤติกรรมการเลือกกินอาหารที่ดีต่อสุขภาพและส่งผลต่อการลดน้ำหนักตัวรวมถึงดัชนีมวลกายได้อย่างยั่งยืน

### 3. อิทธิพลทางสังคมและกลุ่มสัมพันธ์ในการควบคุมน้ำหนัก
ความพึงพอใจในระดับสูงยิ่งของกลุ่มตัวอย่างต่อกิจกรรมการแข่งขันควบคุมน้ำหนัก ($\bar{x} = 4.70$, S.D. = 0.46) ชี้ชัดว่า การกระตุ้นพฤติกรรมสุขภาพจำต้องอาศัยกลไกทางสังคมควบคู่กับตัวระบบ อภิปรายได้ว่า กิจกรรมการแข่งขันควบคุมน้ำหนักร่วมกับการให้รางวัลสะสมแต้มตามทฤษฎีเกมมิฟิเคชัน ช่วยดึงดูดใจและกระตุ้นแรงขับภายนอกร่วมกับแรงสนับสนุนจากกลุ่มเพื่อนร่วมงานในองค์กร ส่งผลให้เกิดพฤติกรรมการดูแลสุขภาพอย่างสม่ำเสมอ สอดรับกับผลงานวิจัยของ **Leahey, Kumar, Weinberg, and Wing (2012)** ที่ชี้ชัดว่าการแข่งขันลดน้ำหนักระดับกลุ่มจะเหนี่ยวนำอิทธิพลทางสังคมเชิงบวก (Social Influence) และกระตุ้นให้ผู้ร่วมแข่งขันสามารถทำตามแผนโภชนาการและบรรลุผลลัพธ์ลดน้ำหนักได้มีนัยสำคัญมากกว่าการควบคุมน้ำหนักเพียงคนเดียว
