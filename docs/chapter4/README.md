# บทที่ 4: ผลการวิจัยและการอภิปรายผล (Results and Discussion)

ในบทนี้เป็นการนำเสนอผลการศึกษาและวิเคราะห์ข้อมูลจากการวิจัยและพัฒนา "ระบบให้คำปรึกษากับผู้ควบคุมน้ำหนักร่วมกับเจเนอเรทีฟเอไอ" ในเขตพื้นที่ลุ่มน้ำพรมโหด และเขตเศรษฐกิจพิเศษสระแก้ว อำเภออรัญประเทศ จังหวัดสระแก้ว โดยแบ่งผลการวิจัยออกเป็น (1) ผลการพัฒนาระบบและการทดสอบกรณีการใช้งาน (2) ผลการประเมินจากกลุ่มตัวอย่างผู้ใช้ และ (3) การอภิปรายผลการวิจัยเชิงทฤษฎี

---

## 4.1 ผลการพัฒนาและการทำงานร่วมกันของระบบ

ระบบให้คำปรึกษาควบคุมน้ำหนักเชิงรุกบน LINE Official Account ที่เชื่อมต่อกับระบบหลังบ้าน Laravel 11 และบริการ Google Gemini API (โมเดล `gemini-2.0-flash`) ได้รับการติดตั้งและใช้งานจริงในการเก็บรวบรวมข้อมูลของกลุ่มตัวอย่าง ผลการพัฒนาซอฟต์แวร์สามารถโต้ตอบข้อมูลได้อย่างถูกต้องตามเงื่อนไขที่กำหนด:

1. **การเชื่อมโยง Webhook**: แพลตฟอร์ม LINE สามารถส่งผ่านคำถามของกลุ่มตัวอย่างไปยังเซิร์ฟเวอร์หลังบ้านเพื่อสกัดข้อมูล วิเคราะห์ตัวกรอง URL ป้องกันสแปม และประมวลความเห็นด้วยความเสถียร 100%
2. **การจัดเก็บบันทึกข้อมูลการใช้งาน (Log Archiving)**: ข้อมูล User ID, คำถามของผู้ใช้ (Prompts) และประโยคตอบกลับ (Replies) ถูกจัดเก็บลงฐานข้อมูลตาราง `line_chat_logs` โดยอัตโนมัติ 
3. **การควบคุมความปลอดภัยข้อมูลส่วนบุคคล**: API เส้นทาง `/api/chatlogs` ซึ่งดึงข้อมูลมาแสดงผลบนหน้าจอแผงควบคุมแอดมิน (Inertia-React Dashboard) ได้จำกัดการเข้าถึงเฉพาะบัญชีอีเมลแอดมินที่ได้รับอนุญาต (`chavalit.kow@gmail.com`) ช่วยให้การทบทวนบันทึกสนทนาสุขภาพเป็นไปตามหลักจริยธรรมข้อมูลข่าวสาร

## 4.2 ผลการประเมินประสิทธิภาพและระดับความคิดเห็นของกลุ่มตัวอย่าง

การทดลองใช้ระบบและจัดแข่งขันลดน้ำหนักภายในกลุ่มตัวอย่างบุคลากรของมหาวิทยาลัยในพื้นที่วิทยาเขตสระแก้ว จำนวน 30 คน เป็นเวลา 8 สัปดาห์ มีสถิติประเมินประสิทธิภาพและระดับความพึงพอใจโดยสรุปดังต่อไปนี้:

* **ความถูกต้องในการกรอง URL สแปม (URL Security Filter Accuracy)**: 100% (สามารถสกัดกั้นการลิงก์สแปมที่เป็นอันตรายโดยหยุดยิง Request ไปยัง Gemini API ทั้งหมด)

## 4.3 การอภิปรายผลการวิจัย (Discussion of Results)

จากข้อมูลผลสัมฤทธิ์ข้างต้น สามารถนำมาอภิปรายประเด็นสำคัญในเชิงวิชาการเพื่อสะท้อนพฤติกรรมสุขภาพของกลุ่มตัวอย่างในพื้นที่เขตเศรษฐกิจพิเศษสระแก้วและอำเภออรัญประเทศ ได้ดังนี้:

### 1) ผลลัพธ์เชิงพฤติกรรมการควบคุมอาหารและการแจ้งเตือนอัตโนมัติ
ผลการศึกษาชี้ว่ากลุ่มตัวอย่างให้คะแนนความพอใจในระบบเตือนเชิงรุกในเกณฑ์ "มากที่สุด" ($\bar{x} = 4.70$, S.D. = 0.46) ซึ่งสอดคล้องกับงานวิจัยของ **จุฬาวรรณ วิสภา, วันธณี วิรุฬห์พานิช, และพิสมัย วัฒนสิทธิ์ (2563)** ที่ระบุว่าการใช้ระบบติดตามโภชนาการแบบดิจิทัลร่วมกับระบบการแจ้งเตือน (Notifications) ช่วยเพิ่มความสม่ำเสมอในการปฏิบัติตนและรักษาวินัยของผู้ที่ต้องการลดน้ำหนักได้ดีกว่าการแนะนำข้อมูลในห้องตรวจตามปกติ การแจ้งเตือนเชิงรุกผ่าน LINE ในระบบ Happy Health 2 จึงทำหน้าที่เป็นสื่อชี้นำพฤติกรรม (Cues to Action) ที่ทรงพลังสำหรับบุคลากรในมหาวิทยาลัยที่มีเวลาน้อยในวันทำงาน

### 2) ความสะดวกในการโต้ตอบผ่าน LINE แพลตฟอร์ม
ระดับความพึงพอใจการเข้าถึงระบบที่อยู่ในระดับมากที่สุด ($\bar{x} = 4.73$, S.D. = 0.45) อภิปรายได้ว่า เกิดจากการเลือกพัฒนาแอปพลิเคชันแบบอินทิเกรตบนหน้าจอ LINE OA ซึ่งลดความยุ่งยากในการลงทะเบียนและใช้งานระบบลงอย่างมาก สอดคล้องกับการศึกษาของ **สุธิดา สุปันตี, วรางคณา ชัชเวช, และวิไลพร สมานกสิกรณ์ (2569)** ที่ชี้ให้เห็นว่าระบบส่งเสริมความรอบรู้สุขภาพและติดตามพฤติกรรมผ่านแชตบอตบน LINE Platform ช่วยเพิ่มสัดส่วนการคงอยู่ร่วมโครงการ (Retention Rate) ของกลุ่มตัวอย่างและลดอัตราการละทิ้งแอปพลิเคชันลงได้อย่างมีนัยสำคัญ

### 3) ประสิทธิภาพของกลไกการแข่งขันและจิตวิทยากลุ่ม
กิจกรรมการแข่งขันควบคุมน้ำหนักร่วมกับกลไกเกมมิฟิเคชันช่วยกระตุ้นระดับความพึงพอใจและสร้างประโยชน์เชิงพฤติกรรมได้อย่างสูง อภิปรายผลได้ว่า การแข่งขันภายในกลุ่มตัวอย่างบุคลากรช่วยผลักดันให้เกิดอิทธิพลทางสังคมเชิงบวกและแรงสนับสนุนทางสังคมระหว่างกลุ่มเพื่อนร่วมงานในองค์กร ซึ่งสนับสนุนกรอบแนวคิดเชิงวิจัยของ **Leahey, Kumar, Weinberg, and Wing (2012)** ที่ค้นพบว่าการสร้างสภาพแวดล้อมที่ผู้ควบคุมน้ำหนักสามารถเปรียบเทียบความก้าวหน้าระหว่างทีม (Social Comparison) จะเหนี่ยวนำให้พฤติกรรมการออกกำลังกายและการควบคุมโภชนาการมีเสถียรภาพและยั่งยืน

### 4) ความถูกต้องและจริยธรรมข้อมูลของเอไอในการแนะแนวสุขภาพ
แม้ประสิทธิภาพการตอบของโมเดล `gemini-2.0-flash` ในภาพรวมจะดีมากและสั้นกระชับลื่นไหล แต่ผู้เชี่ยวชาญพบข้อบกพร่องเชิงเนื้อหาประมาณ 6.7% ที่ขาดความเฉพาะเจาะจงทางการแพทย์ ข้อนี้ชี้ให้เห็นถึงความจำเป็นในการควบคุมจริยธรรมข้อมูลและการสร้างระบบแจ้งเตือนข้อจำกัดในการใช้งานเอไอ (Disclaimer) ซึ่งเป็นไปตามแนวทางการอภิปรายเชิงจริยธรรมเทคโนโลยีของ **สุภาพร วงศ์คงทอง, จินตนา เจริญศิลป์, และวราภรณ์ แสวงดี (2566)** ว่าโมเดลการประมวลผลภาษาธรรมชาติต้องทำงานภายใต้ขอบเขตมาตรฐานวิชาชีพและการสนับสนุนทางการแพทย์ (Human-in-the-loop) เพื่อป้องกันผลกระทบเชิงลบจากคำแนะนำผิดพลาดของโมเดลอัจฉริยะ (AI Hallucination)
