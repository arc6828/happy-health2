บทที่ 4
ผลการวิจัย
4.1 ผลการออกแบบและพัฒนาแบบจำลอง AI สำหรับการให้คำปรึกษาผู้ควบคุมน้ำหนัก ฝึกฝนแบบจำลองด้วยข้อมูลที่รวบรวมมา โดยสามารถวิเคราะห์และให้คำแนะนำได้อย่างแม่นยำ
เนื้อหาของ อ.ประณมกร
4.2 ผลการออกแบบและพัฒนาแพลตฟอร์มออนไลน์ที่ผู้ควบคุมน้ำหนักสามารถเข้าถึงได้ง่าย โดยรวมฟังก์ชันการให้คำปรึกษาจาก AI การบันทึกและติดตามข้อมูลสุขภาพ การแจ้งเตือน และการสนับสนุนผู้ควบคุมน้ำหนัก จัดทำฐานข้อมูลที่มีความปลอดภัยและเป็นส่วนตัว เพื่อเก็บรักษาข้อมูลของผู้ควบคุมน้ำหนัก และถ่ายทอดการใช้งานแพลตฟอร์มออนไลน์การดูแลสุขภาพสำหรับผู้ควบคุมน้ำหนัก ติดตามการใช้งานและผลลัพธ์จากผู้ควบคุมน้ำหนักที่ใช้แพลตฟอร์ม
เนื้อหาของ อ.ชวลิต
4.3 ผลการอบรมและสนับสนุนความรู้ผู้ควบคุมน้ำหนักด้วยข้อมูลโภชนาการด้วยเนื้อหาที่ถูกต้องเหมาะสม รวมทั้งให้คำปรึกษาด้านโภชนาการและการสนับสนุนทางเทคนิคสำหรับผู้ควบคุมน้ำหนัก
เนื้อหาของ อ.ใยแพร
4.4 ผลการจัดการแข่งขันการลดน้ำหนัก โดยมีการรวบรวมข้อมูลทางการแพทย์ที่เกี่ยวข้อง และประเมินผลลัพธ์ของการควบคุมน้ำหนัก รวมถึงให้คำปรึกษาด้านการออกกำลังกาย
4.4.1 ข้อมูลทั่วไปของกลุ่มตัวอย่างที่เข้าร่วมโปรแกรมแข่งขันการลดน้ำหนักของกลุ่มทดลอง
ข้อมูลทั่วไป พบว่า กลุ่มตัวอย่างส่วนใหญ่เป็นเพศหญิงมากกว่าเพศชาย ร้อยละ 65.8 มีอายุน้อยกว่า 40 ปี ร้อยละ 55.3 รองลงมามีอายุระหว่าง 41-50 ปี ร้อยละ 28.9 และมีอายุตั้งแต่ 51 ปีขึ้นไป ร้อยละ 15.8 (อายุเฉลี่ยเท่ากับ 40.16 ± 8.90 ปี)  ส่วนใหญ่สำเร็จการศึกษาสูงกว่าระดับปริญญาตรี ร้อยละ 57.9 และปริญญาตรี ร้อยละ 42.1 เป็นบุคลากรฝ่ายสนับสนุน ร้อยละ 52.6 และบุคลากรฝ่ายวิชาการ ร้อยละ 47.4 ส่วนใหญ่ไม่มีโรคประจำตัว ร้อยละ 81.6 ดังตารางที่ 4.1
ตารางที่ 4.1 จำนวนและร้อยละข้อมูลทั่วไปของกลุ่มตัวอย่างที่เข้าร่วมโปรแกรมแข่งขันการลดน้ำหนักของกลุ่มทดลอง (n = 38)

4.4.2  การเปรียบเทียบผลการวิเคราะห์องค์ประกอบร่างกาย ได้แก่ น้ำหนัก ค่าดัชนีมวลกาย เปอร์เซ็นต์ไขมันในร่างกาย และมวลกล้ามเนื้อ ก่อนและหลังเข้าร่วมโปรแกรมส่งเสริมสุขภาพโดยประยุกต์ใช้เทคโนโลยีเจเนอเรทีฟเอไอในบุคลากรมหาวิทยาลัย โดยในโปรแกรมมีกิจกรรมการแข่งขันลดน้ำหนักแบบมีเป้าหมายสุขภาพ ชั่งน้ำหนัก วัด BMI เปอร์เซ็นต์ไขมัน และ มวลกล้ามเนื้อ ก่อน–หลัง โปรแกรม ผู้เข้าร่วมตั้งเป้าหมายส่วนตัวผ่านแบบฟอร์ม AI Assistant (เช่น Chatbot สุขภาพ) มีระบบจัดอันดับรายเดือน Top 3 ผู้พัฒนา “สุขภาพดีขึ้นที่สุด” (ไม่ใช่แค่ลดน้ำหนัก) และมีการให้ความรู้ผ่าน Generative AI ระบบ AI ตอบคำถามเฉพาะบุคคลเกี่ยวกับอาหาร การออกกำลังกาย และการจัดการอารมณ์
พบว่า ภายหลังการทดลองกลุ่มตัวอย่างมีองค์ประกอบร่างกายดีขึ้น ได้แก่ ค่าเฉลี่ยของน้ำหนักลดลง (M = 68.77, SD = 19.467) เมื่อเปรียบเทียบกับก่อนการทดลอง (M = 70.46, SD = 20.28) อย่างมีนัยสำคัญทางสถิติ (p-value < .001) ค่าเฉลี่ยของดัชนีมวลกายลดลง (M = 24.21, SD = 3.30) เมื่อเปรียบเทียบกับก่อนการทดลอง (M = 24.84, SD = 3.60) อย่างมีนัยสำคัญทางสถิติ (p-value < .001) ค่าเฉลี่ยเปอร์เซ็นต์ไขมันในร่างกายลดลง(M = 30.11, SD = 7.68) เมื่อเปรียบเทียบกับก่อนการทดลอง (M = 31.59, SD = 7.70) อย่างมีนัยสำคัญทางสถิติ (p-value < .001) และค่าเฉลี่ยของมวลกล้ามเนื้อเพิ่มขึ้น (M = 27.22, SD = 6.88) เมื่อเปรียบเทียบกับก่อนการทดลอง (M = 26.52, SD = 6.77) อย่างมีนัยสำคัญทางสถิติ (p-value =.017) ดังตารางที่ 4.2
ตารางที่ 4.2  ผลการเปรียบเทียบผลการวิเคราะห์องค์ประกอบร่างกาย ได้แก่ น้ำหนัก ค่าดัชนีมวลกาย เปอร์เซ็นต์ไขมันในร่างกาย และมวลกล้ามเนื้อ ก่อนและหลังเข้าร่วมโปรแกรมส่งเสริมสุขภาพโดยประยุกต์ใช้เทคโนโลยีเจเนอเรทีฟเอไอในบุคลากรมหาวิทยาลัย (n = 38)

4.4.3 เปรียบเทียบค่าคะแนนเฉลี่ยความรู้และพฤติกรรมสุขภาพ ก่อนและหลังเข้าร่วมโปรแกรมส่งเสริมสุขภาพโดยประยุกต์ใช้เทคโนโลยีเจเนอเรทีฟเอไอในบุคลากรมหาวิทยาลัย
พบว่า ผลการเปรียบเทียบค่าคะแนนเฉลี่ยความรู้และพฤติกรรมสุขภาพ ก่อนและหลังเข้าร่วมโปรแกรมส่งเสริมสุขภาพโดยประยุกต์ใช้เทคโนโลยีเจเนอเรทีฟเอไอในบุคลากรมหาวิทยาลัย
โดยภายหลังการทดลองกลุ่มตัวอย่างมีค่าคะแนนเฉลี่ยความรู้เกี่ยวกับ 3 อ. ได้แก่ อาหาร ออกกำลังกาย อารมณ์ หลังการทดลองมากกว่าก่อนการทดลองอย่างมีนัยสำคัญทางสถิติ (Mean Difference = -2.18, 95%CI : -2.69 to -1.67, p-value <.001)
โดยภาพรวมค่าเฉลี่ยคะแนนพฤติกรรมการดูแลตนเองหลังการทดลองมากกว่าก่อนการทดลองอย่างมีนัยสำคัญทางสถิติ (Mean Difference = -0.70, 95%CI : -0.86 to -0.53, p-value <.001)
เมื่อพิจารณาเป็นรายด้าน พบว่า ค่าเฉลี่ยตัวแปรพฤติกรรมการดูแลตนเองทั้ง 3 ด้าน หลังการทดลองมากกว่าก่อนการทดลองอย่างมีนัยสำคัญทางสถิติ ได้แก่ พฤติกรรมการบริโภคอาหาร (Mean Difference = -0.56, 95%CI : -0.70 to -0.42, p-value <.001) พฤติกรรมการออกกำลังกาย (Mean Difference = -0.73, 95%CI : -0.93 to -0.53, p-value <.001) และพฤติกรรมการจัดการความเครียด (Mean Difference = -0.71, 95%CI : -0.98 to -0.44, p-value <.001) ดังตารางที่ 4.2
ตารางที่ 4.2 ผลการเปรียบเทียบค่าคะแนนเฉลี่ยความรู้และพฤติกรรมสุขภาพ ก่อนและหลังเข้าร่วมโปรแกรมส่งเสริมสุขภาพโดยประยุกต์ใช้เทคโนโลยีเจเนอเรทีฟเอไอในบุคลากรมหาวิทยาลัย (n = 38)
