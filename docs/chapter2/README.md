# บทที่ 2: เอกสารและงานวิจัยที่เกี่ยวข้อง (Literature Review)

การพัฒนาระบบให้คำปรึกษากับผู้ควบคุมน้ำหนักร่วมกับเจเนอเรทีฟเอไอ จำเป็นต้องอาศัยการทบทวนวรรณกรรม เอกสาร และงานวิจัยที่เกี่ยวข้องเพื่อเป็นกรอบแนวคิดในการพัฒนา ในบทนี้จะอธิบายถึงหัวข้อสำคัญ 4 หัวข้อ ได้แก่ (1) แนวคิดการควบคุมน้ำหนักและพลังงาน (2) เทคโนโลยีเจเนอเรทีฟเอไอและโมเดลภาษาขนาดใหญ่ (3) แพลตฟอร์ม LINE Messaging API และ (4) งานวิจัยที่เกี่ยวข้อง

---

## 2.1 แนวคิดการควบคุมน้ำหนักและพลังงาน (Weight Management and Caloric Balance)

การควบคุมน้ำหนักตัวให้อยู่ในเกณฑ์มาตรฐานเป็นหัวใจสำคัญของการมีสุขภาพดี ดัชนีหลักที่ใช้ประเมินคือ **ดัชนีมวลกาย (Body Mass Index: BMI)** ซึ่งคำนวณจากน้ำหนักตัว (กิโลกรัม) หารด้วยส่วนสูงยกกำลังสอง (เมตร) ค่า BMI ระหว่าง 18.5 - 22.9 ถือเป็นเกณฑ์ปกติ หากสูงกว่า 23.0 ถือว่ามีน้ำหนักเกิน และหากสูงกว่า 25.0 ถือว่าเป็นโรคอ้วนสำหรับประชากรเอเชีย

### 2.1.1 หลักการสมดุลพลังงาน (Caloric Balance)
การเปลี่ยนแปลงของน้ำหนักตัวขึ้นอยู่กับความสัมพันธ์ระหว่างพลังงานที่ได้รับและพลังงานที่ใช้ไป:
1. **พลังงานที่ได้รับ (Energy Intake)**: พลังงานจากการบริโภคอาหารและเครื่องดื่ม วัดหน่วยเป็นกิโลแคลอรี (kcal) สารอาหารหลักที่ให้พลังงานประกอบด้วย คาร์โบไฮเดรต โปรตีน และไขมัน
2. **พลังงานที่ใช้ไป (Energy Expenditure)**: แบ่งออกเป็น 3 ส่วนหลัก ได้แก่
   * **อัตราการเผาผลาญพื้นฐาน (Basal Metabolic Rate: BMR)**: พลังงานขั้นต่ำที่ร่างกายใช้ในการดำรงชีพขณะพัก
   * **พลังงานจากการทำกิจกรรม (Physical Activity Level: PAL)**: พลังงานที่ใช้ในการเคลื่อนไหวร่างกายและการออกกำลังกาย
   * **ผลความร้อนจากอาหาร (Thermic Effect of Food: TEF)**: พลังงานที่ใช้ในการย่อยและดูดซึมสารอาหาร

การควบคุมหรือลดน้ำหนักอย่างถูกวิธีตามหลักการแพทย์และโภชนาการ จะต้องสร้าง **ภาวะพร่องพลังงาน (Caloric Deficit)** คือการบริโภคพลังงานให้น้อยกว่าพลังงานที่ใช้ไป โดยทั่วไปแนะนำให้ลดพลังงานลงประมาณ 500 kcal ต่อวันจากระดับพลังงานที่ต้องการสำหรับการรักษาน้ำหนักตัว (Total Daily Energy Expenditure: TDEE) ซึ่งจะช่วยลดน้ำหนักได้ประมาณ 0.5 กิโลกรัมต่อสัปดาห์อย่างปลอดภัย

## 2.2 เทคโนโลยีเจเนอเรทีฟเอไอและโมเดลภาษาขนาดใหญ่ (Generative AI & LLMs)

**เจเนอเรทีฟเอไอ (Generative AI)** คือสาขาหนึ่งของปัญญาประดิษฐ์ที่มุ่งเน้นการสร้างเนื้อหาใหม่ เช่น ข้อความ รูปภาพ เสียง หรือรหัสคอมพิวเตอร์ โดยมีเทคโนโลยีพื้นฐานที่สำคัญคือ **โมเดลภาษาขนาดใหญ่ (Large Language Models: LLMs)** ซึ่งพัฒนาขึ้นด้วยสถาปัตยกรรมแบบ Transformer (เช่น GPT, Gemini, Claude)

### 2.2.1 จุดเด่นและการประยุกต์ใช้โมเดล Gemini 2.0 Flash
โมเดล **Gemini 2.0 Flash** พัฒนาขึ้นโดย Google เป็นโมเดลที่มีจุดเด่นด้านความเร็วในการตอบสนอง (Low Latency) และมีความสามารถในการประมวลผลข้อมูลหลายรูปแบบ (Multimodal capabilities) ทำให้เหมาะสมอย่างยิ่งสำหรับระบบแชตบอตที่ต้องการการโต้ตอบแบบเรียลไทม์ (Real-time Interaction) 

กระบวนการประมวลผลข้อความของโมเดลประกอบด้วย:
1. **Tokenization**: แปลงคำและประโยคภาษาไทยให้อยู่ในรูปเวกเตอร์ตัวเลข (Tokens)
2. **Contextual Understanding**: วิเคราะห์ความสัมพันธ์ของคำและเจตนา (Intent) ของคำถามผ่านระบบ Attention Mechanism
3. **Content Generation**: ทำนายและสร้างข้อความตอบกลับทีละคำอย่างลื่นไหลและสอดคล้องกับบริบท

การนำ LLM มาช่วยงานให้คำปรึกษาน้ำหนักตัว ช่วยแก้ปัญหาการเขียนสคริปต์ตอบคำถามแบบดั้งเดิม (Rule-based Chatbots) ที่มักตอบคำถามได้จำกัด โดย Gemini สามารถอภิปราย วิเคราะห์ สรุปแคลอรีจากข้อความบรรยาย เช่น "กินกะเพราไข่ดาวและชานมไข่มุกไป มีแคลอรีประมาณเท่าไหร่" ได้อย่างยืดหยุ่น

## 2.3 แพลตฟอร์ม LINE Messaging API

ในประเทศไทย แอปพลิเคชัน LINE เป็นช่องทางการสื่อสารที่ได้รับความนิยมสูงสุด มีจำนวนผู้ใช้งานครอบคลุมประชากรส่วนใหญ่ การนำเสนอบริการสุขภาพผ่านแอปพลิเคชัน LINE จึงช่วยลดกำแพงการเข้าใช้งานเทคโนโลยีและการดาวน์โหลดแอปพลิเคชันใหม่

**LINE Messaging API** ช่วยให้นักพัฒนาสามารถเชื่อมโยงเซิร์ฟเวอร์ของตนเองเข้ากับระบบของ LINE ได้โดยใช้สถาปัตยกรรมแบบ **Webhook** เมื่อผู้ใช้งานพิมพ์ข้อความส่งหาแชตบอต ระบบของ LINE จะส่ง HTTPS POST request ที่บรรจุข้อมูลเหตุการณ์ (Event Objects เช่น text, userId, replyToken) มายัง URL Webhook ที่กำหนดไว้บนเซิร์ฟเวอร์ Laravel ของระบบเพื่อประมวลผลและส่งข้อความตอบกลับไปยัง LINE Platform

## 2.4 งานวิจัยที่เกี่ยวข้อง (Related Research)

จากการศึกษางานวิจัยด้านเทคโนโลยีสุขภาพ (e-Health) และระบบให้คำปรึกษาอัตโนมัติ พบการศึกษาที่สอดคล้องดังนี้:

1. **การยอมรับแชตบอตสุขภาพ**: งานวิจัยของ Fitzpatrick et al. (2017) ที่พัฒนาแชตบอต "Woebot" ชี้ให้เห็นว่าแชตบอตสามารถสร้างความผูกพันและให้คำแนะนำในการปรับเปลี่ยนพฤติกรรมได้อย่างมีนัยสำคัญ เนื่องจากผู้ใช้งานรู้สึกเป็นอิสระจากการตัดสินของมนุษย์ (Non-judgmental Environment)
2. **การบูรณาการ Generative AI ในงานส่งเสริมสุขภาพ**: งานวิจัยในยุคปัจจุบัน (เช่น ChatGPT และ Gemini ในบทบาทผู้ช่วยสุขภาพ) แสดงให้เห็นว่าโมเดลภาษาขนาดใหญ่มีความรู้ความสามารถเทียบเท่านักกำหนดอาหารเบื้องต้น โดยสามารถจัดตารางอาหารที่ตอบโจทย์โรคประจำตัวและเป้าหมายน้ำหนักได้เป็นอย่างดี อย่างไรก็ตาม ข้อควรระวังสูงสุดคือปัญหา "การสร้างข้อมูลเท็จ" (Hallucination) ซึ่งผู้พัฒนาจำเป็นต้องควบคุมการสร้างคำตอบด้วย Prompt Engineering และการสร้างข้อจำกัดคำตอบ (Safety Filters / Disclaimer)
3. **การเข้าถึงง่ายผ่านช่องทางแชตบอตของไทย**: การวิจัยของไทยหลายชิ้นชี้ว่า LINE Bot เป็นส่วนติดต่อผู้ใช้ที่สร้างแรงจูงใจและการมีส่วนร่วมสูงที่สุดสำหรับกลุ่มผู้ป่วยโรคไม่ติดต่อเรื้อรัง (NCDs) เนื่องจากความเรียบง่ายและไม่ต้องศึกษาการใช้งานระบบใหม่
