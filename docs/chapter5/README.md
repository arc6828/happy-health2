# บทที่ 5: สรุปผลและข้อเสนอแนะ (Conclusion and Recommendations)

ในบทสุดท้ายนี้จะสรุปผลการวิจัยและพัฒนาโครงการ "ระบบให้คำปรึกษากับผู้ควบคุมน้ำหนักร่วมกับเจเนอเรทีฟเอไอ" ชี้แจงข้อจำกัดของระบบที่ค้นพบในการประเมินผล และเสนอแนวทางข้อเสนอแนะในการศึกษาและต่อยอดระบบในอนาคตเพื่อประสิทธิภาพการดูแลสุขภาพที่ดียิ่งขึ้น

---

## 5.1 สรุปผลการวิจัย

การดำเนินงานวิจัยนี้บรรลุตามวัตถุประสงค์ที่ตั้งไว้ ดังนี้:
1. **การพัฒนาระบบแชตบอต**: สามารถออกแบบระบบให้คำปรึกษาควบคุมน้ำหนักบนแอปพลิเคชัน LINE ที่เชื่อมต่อกับระบบหลังบ้าน Laravel และบริการ Google Gemini API (โมเดล `gemini-2.0-flash`) ได้สำเร็จ ทำหน้าที่เป็นผู้ช่วยสุขภาพส่วนบุคคลในการให้คำแนะนำด้านโภชนาการและการออกกำลังกาย
2. **การพัฒนาระบบจัดเก็บข้อมูล (Chat Logs)**: ระบบสามารถดักรับเหตุการณ์ผ่าน Webhook และบันทึกประวัติการใช้งาน (LINE User ID, Prompt, AI Response) ลงฐานข้อมูล MySQL ได้อย่างถูกต้องครบถ้วน พร้อมพัฒนา API ให้บริการเรียกดูข้อมูลเพื่อประโยชน์ในการวิเคราะห์และควบคุมระบบย้อนหลัง
3. **การประเมินกลไกและการควบคุมคำตอบ (Prompt Engineering)**: การเพิ่มเงื่อนไข "ไม่เกิน 1 ย่อหน้า" เข้าไปในคำสั่งสามารถจำกัดการตอบสนองของโมเดล AI ได้อย่างสมบูรณ์แบบ ทำให้คำแนะนำสั้นกระชับ เหมาะกับขนาดหน้าจอสมาร์ตโฟน และมีการตอบกลับที่รวดเร็ว ( latency ต่ำ) ทำให้ผู้ใช้พึงพอใจและมีพฤติกรรมการโต้ตอบที่ต่อเนื่อง

---

## 5.2 ข้อจำกัดของระบบ

แม้ว่าระบบจะทำงานได้อย่างมีประสิทธิภาพในการให้คำปรึกษาทั่วไป แต่การวิเคราะห์ยังพบข้อจำกัดสำคัญบางประการ ได้แก่:
1. **ข้อจำกัดเชิงข้อมูลภาพ (Text-only input)**: ระบบในปัจจุบันจำกัดเฉพาะการรับคำถามรูปแบบข้อความธรรมดา (Text Input) ยังไม่รองรับการส่งภาพถ่ายอาหารเพื่อวิเคราะห์หรือคำนวณสารอาหารโดยตรง
2. **ความถูกต้องทางการแพทย์ระดับลึก (Medical Disclaimers)**: ข้อมูลตอบกลับจากเจเนอเรทีฟเอไออ้างอิงจากฐานความรู้ขนาดใหญ่ที่โมเดลได้รับการเทรนมา ซึ่งอาจให้คำแนะนำทั่วไปที่ไม่เหมาะกับผู้ที่มีภาวะสุขภาพเฉพาะเจาะจงหรือโรคประจำตัวร้ายแรง เช่น ผู้ป่วยโรคไตเสื่อม (ที่ต้องคุมปริมาณโปรตีนและโซเดียมอย่างเคร่งครัด) หรือผู้ป่วยโรคเบาหวานขั้นรุนแรง
3. **การพึ่งพิงบริการภายนอก (API Dependency)**: ความเร็วและความเสถียรในการทำงานขึ้นอยู่กับความพร้อมของระบบ Google Gemini API และเครือข่ายอินเทอร์เน็ตของ LINE Platform หากผู้ให้บริการระบบล่มหรือมีการจำกัดอัตราการเรียกใช้ (Rate Limiting) แชตบอตอาจตอบกลับล่าช้าหรือหยุดทำงานชั่วคราว

---

## 5.3 ข้อเสนอแนะในการวิจัยครั้งต่อไป

เพื่อให้ระบบเอไอผู้ช่วยควบคุมน้ำหนักมีความเป็นอัจฉริยะและอำนวยความสะดวกในการใช้งานที่ครอบคลุมมากยิ่งขึ้น มีแนวทางพัฒนาต่อยอดและหัวข้องานวิจัยในอนาคตดังต่อไปนี้:

### 1. การบูรณาการข้อมูลหลายรูปแบบ (Multimodal AI Capabilities)
ควรขยายขีดความสามารถการรับค่าของระบบ โดยเชื่อมต่อฟีเจอร์ Multimodal ของโมเดล Gemini เพื่อตรวจจับรูปภาพอาหารที่ผู้ใช้ถ่ายส่งเข้ามาผ่าน LINE แล้วใช้เทคนิคการวิเคราะห์ภาพ (Image Recognition) ในการประมาณค่าแคลอรีและแจกแจงสารอาหาร (สัดส่วนคาร์บ โปรตีน ไขมัน) ซึ่งจะช่วยลดความยุ่งยากในการพิมพ์เมนูอาหารของผู้ใช้

### 2. การสร้างแผนโภชนาการแบบเจาะจงบุคคล (Highly Personalized Profiles)
ควรต่อยอดฝั่งแดชบอร์ด Laravel/React ให้เก็บข้อมูลส่วนตัวของผู้ใช้เพิ่มเติม เช่น อายุ เพศ น้ำหนักปัจจุบัน ส่วนสูง เป้าหมายน้ำหนัก และระดับกิจกรรมทางกาย เพื่อนำมาคำนวณค่า BMR และ TDEE ของผู้ใช้คนนั้นเก็บไว้ในฐานข้อมูล และปรับปรุง Prompt ให้ส่งข้อมูล Profile เหล่านี้ควบคู่ไปกับคำถาม เพื่อให้เอไอสามารถให้คำแนะนำที่เหมาะกับความต้องการใช้พลังงานของบุคคลนั้นอย่างแม่นยำยิ่งขึ้น

### 3. การประมวลกราฟและการแสดงความก้าวหน้า (Data Visualization Dashboard)
พัฒนาส่วนหน้าบ้าน (Frontend) ของแอปพลิเคชัน Happy Health 2 เพื่อเชื่อมโยงกับฐานข้อมูล เพื่อดึงสถิติน้ำหนัก ประวัติคำถาม และการเผาผลาญในแต่ละวันมาแสดงผลเป็นกราฟเส้นแสดงความก้าวหน้า ช่วยสร้างแรงจูงใจ (Gamification and Motivation) ให้กับผู้ใช้งานในการลดน้ำหนักระยะยาว
