# บทที่ 5: สรุปผลและข้อเสนอแนะ (Conclusion and Recommendations)

ในบทนี้จะนำเสนอการสรุปผลสรุปจากการดำเนินการวิจัยและพัฒนาโครงการ "ระบบให้คำปรึกษากับผู้ควบคุมน้ำหนักร่วมกับเจเนอเรทีฟเอไอ" ในเขตพื้นที่ลุ่มน้ำพรมโหด และเขตเศรษฐกิจพิเศษสระแก้ว อำเภออรัญประเทศ จังหวัดสระแก้ว ตลอดจนนำเสนอข้อจำกัดสำคัญของระบบและข้อเสนอแนะในการพัฒนาเพื่อปรับใช้ประโยชน์วิชาการในอนาคต

---

## 5.1 สรุปผลการวิจัย

การดำเนินงานวิจัยครั้งนี้ประสบผลสำเร็จบรรลุตามวัตถุประสงค์ของการศึกษาวิจัย โดยมีข้อสรุปที่สำคัญดังนี้:

1. **การพัฒนาระบบเทคโนโลยี (LINE & Laravel Webhook)**: คณะผู้วิจัยสามารถออกแบบและพัฒนาแพลตฟอร์มออนไลน์เพื่อสุขภาพบนแอปพลิเคชัน LINE เชื่อมโยงผ่าน LINE Messaging API เข้ากับระบบเซิร์ฟเวอร์หลังบ้านด้วย Laravel 11 และฐานข้อมูล MySQL สำหรับจัดเก็บประวัติการสนทนาสุขภาพในตาราง `line_chat_logs` ได้อย่างสมบูรณ์แบบ
2. **การบูรณาการเจเนอเรทีฟเอไอ (Generative AI & Prompt Engineering)**: การเรียกใช้บริการ Google Gemini API ผ่านโมเดล `gemini-2.0-flash` ควบคู่กับการควบคุมประโยค Prompt สรุปไม่เกิน 1 ย่อหน้า ช่วยให้ระบบตอบสนองคำถามด้านโภชนาการและการออกกำลังกายแก่ผู้ควบคุมน้ำหนักได้กระชับ รวดเร็ว (ความเร็วเฉลี่ย 2.4 วินาที) และประหยัดค่าประมวลผลโทเคน
3. **ผลลัพธ์การประเมินจากกลุ่มตัวอย่าง**: การทดลองใช้งานจริงในกลุ่มตัวอย่างบุคลากรของมหาวิทยาลัยในจังหวัดสระแก้วจำนวน 30 ราย แสดงระดับความพึงพอใจต่อระบบโดยรวมในเกณฑ์ **มากที่สุด** ($\bar{x} = 4.59$, S.D. = 0.49) โดยเฉพาะอย่างยิ่งมิติความสะดวกในการโต้ตอบผ่าน LINE แพลตฟอร์ม ($\bar{x} = 4.73$, S.D. = 0.45) และความพึงพอใจต่อกิจกรรมการถ่ายทอดเทคโนโลยีและการแข่งขันลดน้ำหนักภาพรวมอยู่ในเกณฑ์ **มากที่สุด** ($\bar{x} = 4.62$, S.D. = 0.50)

## 5.2 ข้อจำกัดของระบบและการวิจัย

จากการศึกษาวิจัยและติดตามประเมินผล มีข้อจำกัดสำคัญที่ค้นพบในระบบปัจจุบันซึ่งเป็นประเด็นพิจารณาสำหรับการนำไปใช้งาน ได้แก่:

1. **ข้อจำกัดเชิงข้อมูลเข้า (Text-only limitation)**: ระบบยังรองรับเฉพาะข้อมูลเข้าที่เป็นข้อความธรรมดา (Text input) ยังไม่สามารถรับภาพถ่ายจานอาหารที่กลุ่มตัวอย่างบริโภคมาทำการประมาณค่าสารอาหารแบบอัตโนมัติได้
2. **ความเข้าใจบริบทอาหารเชิงพื้นที่และวัฒนธรรมชายแดน**: ข้อมูลประมวลผลของโมเดลภาษาระดับสากล (Gemini API) ในบางกรณีขาดความเข้าใจเชิงลึกเกี่ยวกับวัฒนธรรมโภชนาการท้องถิ่นในเขตเศรษฐกิจพิเศษสระแก้วหรือพื้นที่ลุ่มน้ำพรมโหด ซึ่งเป็นพื้นที่ชายแดนไทย-กัมพูชา ทำให้คำแนะนำเมนูอาหารพื้นเมืองหรือชื่อวัตถุดิบท้องถิ่นมีข้อคลาดเคลื่อนเชิงแคลอรี
3. **ข้อจำกัดความเสี่ยงทางการแพทย์ระดับโรคประจำตัว**: คำแนะนำของเจเนอเรทีฟเอไออ้างอิงฐานความรู้ทั่วไป ไม่เหมาะสำหรับผู้ใช้ที่มีโรคประจำตัวร้ายแรงที่มีข้อจำกัดโภชนาการเฉพาะโรค (เช่น โรคไตวายเรื้อรังที่จำกัดระดับโซเดียม โปแตสเซียม และโปรตีนอย่างเคร่งครัด) ซึ่งจำเป็นต้องผ่านการประเมินจากแพทย์และนักกำหนดอาหารโดยตรง
4. **การพึ่งพาโครงสร้างระบบภายนอก (Third-party Dependency)**: อัตราความเร็วและความเสถียรในการทำงานขึ้นอยู่กับสภาพการจราจรเครือข่ายอินเทอร์เน็ต ระบบเซิร์ฟเวอร์ LINE Platform และการประมวลผลฝั่ง Google Gemini API หากระบบภายนอกเหล่านี้ขัดข้องหรือเกิดข้อจำกัดโควตาการเรียกใช้งาน (Rate limit) ระบบแชตบอตแนะนำสุขภาพอาจเกิดการตอบกลับล่าช้า

## 5.3 ข้อเสนอแนะในการวิจัยและพัฒนาครั้งต่อไป

เพื่อยกระดับระบบให้คำปรึกษาสำหรับผู้ควบคุมน้ำหนักให้มีประสิทธิภาพและก้าวหน้ายิ่งขึ้น คณะผู้วิจัยเสนอแนะแนวทางการต่อยอดระบบในอนาคตดังต่อไปนี้:

### 1) การเชื่อมโยงข้อมูลหลากรูปแบบ (Multimodal AI Implementation)
ควรปรับปรุงระบบให้รับภาพถ่ายอาหาร (Food Photo Capture) ผ่านห้องแชต LINE โดยใช้ความสามารถ Multimodal ของโมเดลเอไอในการระบุชนิดอาหาร ประมาณค่าน้ำหนักดิบ และคำนวณแคลอรีอัตโนมัติ เพื่อลดความยุ่งยากในขั้นตอนการป้อนข้อมูลของผู้ใช้งาน

### 2) การสร้างประวัติสุขภาพเฉพาะรายบุคคล (Highly Personalized Profiles)
ควรต่อยอดระบบหลังบ้านให้เชื่อมโยงกับฐานข้อมูลเวชระเบียนส่วนบุคคลหรือสถิติต่าง ๆ ของผู้ใช้ (เช่น อายุ เพศ มวลน้ำหนักปัจจุบัน เป้าหมายการลดน้ำหนัก และโรคประจำตัว) และส่งข้อมูลเหล่านี้ร่วมเข้าไปใน System Prompt ในการเรียกใช้ Gemini API ทุกครั้ง เพื่อให้ได้คำแนะนำแผนการกินและการออกกำลังกายที่เจาะจงเฉพาะตัวบุคคลอย่างปลอดภัยที่สุด

### 3) การขยายผลสู่ประชากรกลุ่มเป้าหมายในวงกว้าง
ในอนาคต ควรศึกษาและทดสอบการประยุกต์ใช้งานแชตบอตแนะนำสุขภาพร่วมกับชุมชนหรือประชากรกลุ่มอื่น ๆ ทั่วไปในพื้นที่เศรษฐกิจพิเศษสระแก้วและอำเภออรัญประเทศ เพื่อขยายขอบเขตสถิติการใช้งาน นำผลการวิจัยไปประยุกต์ใช้ในการส่งเสริมการพัฒนาสุขภาวะของชุมชนชายแดนเชิงลึกต่อไป
