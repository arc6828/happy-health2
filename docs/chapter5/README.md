# บทที่ 5: สรุปผลการวิจัยและข้อเสนอแนะ (Conclusion and Recommendations)

ที่อยู่เว็บไซต์อย่างเป็นทางการของโครงการ: **[https://happyhealthhappyheart.com](https://happyhealthhappyheart.com)**

ในบทนี้เป็นการนำเสนอสรุปผลการวิจัย ข้อจำกัด และข้อเสนอแนะจากการศึกษา พัฒนา และทดสอบระบบให้คำปรึกษากับผู้ควบคุมน้ำหนักร่วมกับเจเนอเรทีฟเอไอ (Google Gemini 3.6 Flash) ผ่านแพลตฟอร์มออนไลน์ LINE OA และเว็บไซต์ **https://happyhealthhappyheart.com** โดยสรุปสาระสำคัญตามวัตถุประสงค์การวิจัยทั้ง 4 ข้อ ดังนี้:

---

## 5.1 สรุปผลการวิจัย

การดำเนินงานวิจัยครั้งนี้ประสบผลสำเร็จลุล่วงบรรลุตามวัตถุประสงค์ของการศึกษาวิจัยครบถ้วนทั้ง 4 ประการ โดยมีสรุปผลการดำเนินงานดังนี้:

1) **การพัฒนาแบบจำลอง AI สำหรับการให้คำปรึกษาเฉพาะบุคคล (สอดคล้องกับวัตถุประสงค์ข้อที่ 1.2.1)**
   คณะผู้วิจัยได้พัฒนาและปรับแต่งแบบจำลองปัญญาประดิษฐ์เชิงสร้างสรรค์ Google Gemini 3.6 Flash ผ่าน API ร่วมกับการทำ Prompt Engineering และการสร้างกลไกสอดแทรกบริบทส่วนบุคคล (Personalized Context Injection) ซึ่งดึงค่าสรีระ BMR, TDEE, ค่าน้ำหนักตัวล่าสุด และระดับกิจกรรมจากฐานข้อมูลมาประมวลผลร่วมโดยอัตโนมัติ พร้อมทั้งพัฒนาฟังก์ชันสแกนวิเคราะห์แคลอรีและสารอาหารจากรูปถ่ายอาหาร (Multimodal AI) ได้สำเร็จ โดยระบบควบคุมผลลัพธ์คำตอบให้อยู่ในกรอบความปลอดภัย สุภาพ กระชับจบภายใน 1 ย่อหน้า และมีระบบคัดกรองสแกน URL ป้องกันสแปมได้ถูกต้อง 100%

2) **การพัฒนาแพลตฟอร์มออนไลน์และสถาปัตยกรรมความปลอดภัย (สอดคล้องกับวัตถุประสงค์ข้อที่ 1.2.2)**
   คณะผู้วิจัยได้สร้างระบบแพลตฟอร์มออนไลน์เชื่อมโยงบริการหลังบ้าน Laravel 12, LINE Webhook API, แดชบอร์ดสำหรับผู้ดูแลระบบ (Admin Dashboard) ในการติดตามประวัติและปรับสลับโมเดล AI ไดนามิก, แดชบอร์ดผู้ใช้งานทั่วไป (User Dashboard), กระดานผู้นำการแข่งขันลดน้ำหนักแบบไม่เปิดเผยตัวตน (Anonymous Leaderboard) และติดตั้งบนโดเมนทางการ [https://happyhealthhappyheart.com](https://happyhealthhappyheart.com) โดยระบบมีความเร็วในการตอบกลับเฉลี่ย 2.4 วินาที มีความเสถียรภาพสูงถึง 99.8% และปฏิบัติตามมาตรฐาน พ.ร.บ. คุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 (PDPA) อย่างเคร่งครัด

3) **การอบรม ถ่ายทอดเทคโนโลยี และการเผยแพร่คลังความรู้โภชนาการ (สอดคล้องกับวัตถุประสงค์ข้อที่ 1.2.3)**
   คณะผู้วิจัยได้จัดกิจกรรมอบรมเชิงปฏิบัติการ (Workshop) สอนขั้นตอนการใช้งานระบบร่วมกับการให้ความรู้ด้านโภชนาการและการจำกัดแคลอรี (Caloric Deficit) พร้อมแจกจ่ายคู่มือใช้งานแชตบอต LINE และคู่มือระบบเว็บ รวมทั้งจัดทำคลังบทความสื่อโภชนาการและการออกกำลังกายเผยแพร่บนบล็อก Medium (Digital Media Hub) ผลการประเมินพบว่าความพึงพอใจต่อระบบแอปพลิเคชันและการแนะแนวสุขภาพอยู่ในเกณฑ์มากที่สุด ($\bar{x} = 4.59$, S.D. = 0.49) และความพึงพอใจต่อการจัดกิจกรรมอบรมอยู่ในเกณฑ์มากที่สุด ($\bar{x} = 4.62$, S.D. = 0.50)

4) **ผลสัมฤทธิ์การแข่งขันลดน้ำหนักและการประเมินผลเชิงตัวเลข (สอดคล้องกับวัตถุประสงค์ข้อที่ 1.2.4)**
   จากการดำเนินโครงการแข่งขันควบคุมน้ำหนักเป็นเวลา 8 สัปดาห์ ร่วมกับการประเมินผลเชิงการแพทย์ในกลุ่มตัวอย่างบุคลากรมหาวิทยาลัย $n = 38$ ราย พบว่า กลุ่มตัวอย่างมีองค์ประกอบร่างกาย พฤติกรรมสุขภาพ และความรู้ปรับตัวดีขึ้นอย่างมีนัยสำคัญทางสถิติ ได้แก่ น้ำหนักตัวลดลงเฉลี่ย 1.69 กิโลกรัม ($p < .001$), BMI ลดลงเฉลี่ย 0.63 kg/m² ($p < .001$), เปอร์เซ็นต์ไขมันลดลงเฉลี่ย 1.36% ($p < .001$), มวลกล้ามเนื้อเพิ่มขึ้นเฉลี่ย 0.70 กิโลกรัม ($p = .017$), คะแนนความรู้ 3 อ. เพิ่มขึ้น 2.18 คะแนน ($p < .001$) และคะแนนพฤติกรรมสุขภาพการดูแลตนเองโดยภาพรวมเพิ่มขึ้น 0.70 คะแนน ($p < .001$)

## 5.2 ข้อจำกัดของการวิจัย

แม้การศึกษาวิจัยจะบรรลุผลตามเป้าหมาย แต่ยังมีข้อจำกัดบางประการที่ควรนำมาพิจารณา ดังนี้:

1) **ข้อจำกัดความเสี่ยงทางการแพทย์ในผู้มีโรคประจำตัวร้ายแรง**
   คำแนะนำของเจเนอเรทีฟเอไออ้างอิงฐานความรู้โภชนาการและการออกกำลังกายระดับทั่วไปสำหรับบุคคลวัยผู้ใหญ่ปกติ ระบบจึงไม่รองรับผู้ป่วยที่มีโรคประจำตัวร้ายแรงที่มีข้อจำกัดโภชนาการเฉพาะโรค (เช่น โรคไตวายเรื้อรังที่ต้องจำกัดโซเดียมและโปรตีนอย่างเคร่งครัด หรือโรคหัวใจขั้นรุนแรง) ซึ่งจำเป็นต้องได้รับการดูแลจากแพทย์และนักกำหนดอาหารโดยตรง

2) **ความเข้าใจบริบทอาหารและเมนูพื้นเมืองเฉพาะถิ่น**
   โมเดลภาษาขนาดใหญ่ (Gemini 3.6 Flash) ได้รับการฝึกฝนจากคลังข้อมูลระดับสากล ในบางกรณีอาจมีความคลาดเคลื่อนในการประมาณค่าพลังงานแคลอรีสำหรับเมนูอาหารพื้นบ้านเฉพาะถิ่นของไทยที่มีส่วนผสมไม่เป็นมาตรฐาน

3) **การพึ่งพาโครงสร้างเครือข่ายและระบบภายนอก (Third-party Dependency)**
   ความเร็วและความเสถียรในการโต้ตอบขึ้นอยู่กับระบบเซิร์ฟเวอร์ LINE Platform, การเชื่อมต่ออินเทอร์เน็ตของสมาร์ตโฟนผู้ใช้ และโควตาการเรียกใช้งาน Google Gemini API หากระบบภายนอกเกิดการตอบกลับล่าช้าหรือการจราจรเครือข่ายหนาแน่น อาจส่งผลต่อ Response Latency ของแชตบอตได้

## 5.3 ข้อเสนอแนะในการวิจัยและพัฒนาครั้งต่อไป

เพื่อยกระดับแพลตฟอร์มและระบบปัญญาประดิษฐ์ให้มีประสิทธิภาพสูงสุดในอนาคต คณะผู้วิจัยมีข้อเสนอแนะดังนี้:

### 5.3.1 ข้อเสนอแนะในการนำผลการวิจัยไปใช้ประโยชน์

1) **การนำไปใช้เป็นผู้ช่วยส่งเสริมสุขภาพในองค์กร**: สามารถนำแพลตฟอร์ม **https://happyhealthhappyheart.com** และระบบแชตบอต LINE OA ไปประยุกต์ใช้เป็นเครื่องมือส่งเสริมสุขภาพบุคลากร (Corporate Wellness) สำหรับหน่วยงานหรือองค์กรต่าง ๆ เพื่อกระตุ้นการมีส่วนร่วมและปรับพฤติกรรมสุขภาพของพนักงาน

2) **การใช้เป็นสื่อเสริมการเรียนรู้ด้านโภชนาการ**: สามารถนำคลังบทความ Medium (Digital Media Hub) และระบบคำนวณ BMR/TDEE ไปใช้เป็นสื่อการสอนเสริมสำหรับบุคลากรสาธารณสุขหรือครูผู้สอนสุขศึกษาในการถ่ายทอดความรู้โภชนาการแก่ประชาชน

### 5.3.2 ข้อเสนอแนะในการศึกษาวิจัยครั้งต่อไป

1) **การพัฒนาฐานข้อมูลองค์ความรู้เมนูอาหารไทยเฉพาะถิ่น (RAG Architecture)**: ควรพัฒนาระบบ Retrieval-Augmented Generation (RAG) โดยเชื่อมโยงระบบเข้ากับฐานข้อมูลโภชนาการอาหารไทยของกรมอนามัย หรือสถาบันโภชนาการ มหาวิทยาลัยมหิดล เพื่อให้เอไอสามารถประเมินแคลอรีอาหารไทยและอาหารท้องถิ่นได้อย่างแม่นยำยิ่งขึ้น

2) **การเชื่อมต่อกับอุปกรณ์สวมใส่ติดตามสุขภาพ (Wearable Devices Integration)**: ควรขยายขีดความสามารถระบบหลังบ้านให้สามารถเชื่อมต่อ API ข้อมูลจากอุปกรณ์สวมใส่ เช่น Apple Health, Google Fit หรือ Smartwatch เพื่อดึงค่าการก้าวเดิน อัตราการเต้นของหัวใจ และพลังงานที่เผาผลาญจริงรายวันมาประมวลผลร่วมกับปัญญาประดิษฐ์โดยอัตโนมัติ

3) **การขยายผลการศึกษาวิจัยในกลุ่มประชากรวงกว้าง**: ควรขยายผลการทดลองวิจัยไปยังกลุ่มประชากรที่มีความหลากหลายในพื้นที่ต่าง ๆ เช่น กลุ่มประชาชนในเขตพื้นที่ชายแดนหรือชุมชนท้องถิ่น เพื่อประเมินผลสัมฤทธิ์เชิงพฤติกรรมและติดตามผลสุขภาพในระยะยาว (Longitudinal Study) 1 ปีขึ้นไป
