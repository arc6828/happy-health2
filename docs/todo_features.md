## 2. ส่วนระบบแชตบอตแนะนำสุขภาพ (LINE Chatbot Backend)

### [x] 2.1 ระบบยืนยันความปลอดภัยลายเซ็นของ LINE (LINE Signature Verification)
* **รายละเอียด**: เพิ่มระบบคัดกรองความปลอดภัยระดับเส้นทาง Webhook ป้องกันการส่งคำขอปลอมแปลง (Request Forgery)
* **สเปกย่อย**:
  * เขียนฟังก์ชันมิดเดิลแวร์ (Middleware) หรือตัวตรวจสอบใน [`LineWebhookController.php`](file:///e:/chavalit/laravel/happy-health2/app/Http/Controllers/Api/LineWebhookController.php) เพื่อคำนวณ Signature ตรวจสอบค่าแฮช SHA256 ร่วมกับค่า LINE Channel Secret ก่อนเริ่มประมวลข้อความจากอินพุตภายนอก

### [x] 2.2 การบูรณาการข้อมูลหลายรูปแบบ (Multimodal AI Capabilities)
* **รายละเอียด**: ขยายขีดความสามารถการรับค่าของแชตบอตให้รองรับไฟล์สื่ออื่นนอกเหนือจากข้อความตัวอักษร
* **สเปกย่อย**:
  * ดักรับ Event ข้อความประเภทรูปภาพ (`image`) จาก LINE Platform
  * ดึงข้อมูลไฟล์รูปภาพอาหารจาก LINE Server ส่งต่อไปยัง Gemini API เพื่อทำ Image Recognition ประมาณค่าน้ำหนักสารอาหารเบื้องต้นจากรูปถ่าย

### [x] 2.3 การแนะแนวแผนเฉพาะบุคคล (Personalized Context Injection)
* **รายละเอียด**: ปรับปรุงให้ AI สามารถรับรู้ประวัติร่างกายของผู้ใช้เพื่อการตอบคำถามอย่างเจาะจงรายบุคคล
* **สเปกย่อย**:
  * ระบบดึงข้อมูลจากตารางผู้ใช้เพื่อนำประวัติน้ำหนัก ส่วนสูง ค่า BMR และ TDEE รวมถึงโรคประจำตัวมาประกอบร่วมในข้อมูลบริบท (Context injection) ก่อนส่งไปยัง Gemini API เพื่อให้เอไอออกแบบสูตรคำนวณแคลอรีที่ตรงกับเป้าหมายของผู้ใช้รายนั้นที่สุด

## 3. ส่วนระบบบริการผู้ใช้ทั่วไปผ่านหน้าเว็บไซต์ (Web-based User Portal / Web Chat Interface)

### [x] 3.1 ระบบห้องสนทนาแนะนำสุขภาพบนเว็บ (Web-based Chat Interface)
* **รายละเอียด**: พัฒนาตัวประสานการแชต (Chat Widget UI) บนหน้าเว็บไซต์หลัก เพื่อเป็นทางเลือกในการพิมพ์สนทนาถาม-ตอบข้อมูลสุขภาพกับเจเนอเรทีฟเอไอได้โดยตรงโดยไม่ต้องใช้งานผ่าน LINE OA
* **สเปกย่อย**:
  * พัฒนาหน้าจอห้องสนทนาโต้ตอบแบบเรียลไทม์ (Real-time Chat UI Layout) บน React Frontend 
  * จัดทำ API Endpoint สำหรับส่งออกข้อความคำถามจากหน้าเว็บไปยังหลังบ้านเพื่อเรียกใช้ฟังก์ชัน `callGemini(...)` และแสดงผลคำแนะนำกลับมายังแผงแชตของผู้ใช้

### [x] 3.2 แผงควบคุมและฟอร์มบันทึกสุขภาพส่วนบุคคลบนเว็บ (User Weight & Diet Tracking Panel)
* **รายละเอียด**: พัฒนาพอร์ตทัลสำหรับผู้ใช้ทั่วไป (User Portal) ให้สามารถเข้ามาทำกิจกรรมดูแลสุขภาพและควบคุมอาหารบนเว็บไซต์ได้เช่นเดียวกับบน LINE
* **สเปกย่อย**:
  * พัฒนาระบบบันทึกข้อมูลโภชนาการประจำวัน (แคลอรีที่กินเข้าไป) และน้ำหนักตัวส่วนบุคคล
  * ทำการแสดงผลกราฟระดับแคลอรีคงเหลือที่กินได้ในวันนั้น ๆ (Daily Calorie Tracker Panel) เพื่อสร้างแรงจูงใจและการแสดงผลลัพธ์สุขภาพเฉพาะบุคคล

## 4. ส่วนส่งเสริมความรู้และการจัดการกิจกรรมการแข่งขัน (Education & Gamification Portal)

### [x] 4.1 คลังสื่อการเรียนรู้ออนไลน์ส่งเสริมสุขภาพ (Educational Media Hub)
* **รายละเอียด**: จัดทำระบบคลังความรู้ด้านโภชนาการร้อยละ 80 และการออกกำลังกายการดูแลสุขภาพทั่วไปร้อยละ 20 ในรูปแบบบทความ โบรชัวร์อิเล็กทรอนิกส์ หรือวิดีโอแนะนำ สอดคล้องกับวัตถุประสงค์ในการสนับสนุนความรู้และประโยชน์ที่คาดว่าจะได้รับ
* **สเปกย่อย**:
  * หน้าเพจสำหรับจัดแสดงและแบ่งหมวดหมู่สื่อความรู้ (โภชนาการ / การออกกำลังกายและการดูแลสุขภาพทั่วไป)
  * พัฒนาระบบหลังบ้านสำหรับอัปโหลด จัดการบทความ ลิงก์รูปภาพประกอบ และลิงก์วิดีโอแนะแนว
  * พัฒนาเมนูดึงสื่อความรู้ไปแสดงผลผ่าน Rich Menu ของ LINE OA อีกหนึ่งช่องทาง

### [x] 4.2 ระบบกระดานผู้นำการแข่งขันลดน้ำหนักแบบไม่เปิดเผยตัวตน (Anonymous Weight Loss Leaderboard)
* **รายละเอียด**: ระบบคำนวณและจัดแสดงผลการแข่งขันลดน้ำหนักของกลุ่มตัวอย่าง เพื่อสร้างแรงจูงใจและการเปรียบเทียบเชิงบวก
* **สเปกย่อย**:
  * ระบบคำนวณร้อยละการลดน้ำหนักเปรียบเทียบจากน้ำหนักตั้งต้นและน้ำหนักล่าสุดโดยอัตโนมัติ
  * ตารางแสดงผลอันดับกระดานผู้นำบนหน้าเว็บ โดยแสดงเป็นรหัสนามแฝงผู้ใช้ (เช่น User_01, User_02) เพื่อรักษาความปลอดภัยและความเป็นส่วนตัวด้านข้อมูลสุขภาพส่วนบุคคล

### [x] 4.3 ระบบช่วยเหลือผู้ใช้งานและติดต่อสนับสนุนทางเทคนิค (User Helpdesk & Technical Support Channel)
* **รายละเอียด**: เพิ่มช่องทางการแก้ไขปัญหาเชิงเทคนิคและการแนะแนวปัญหาในการเข้าถึงแอปพลิเคชันให้กับกลุ่มตัวอย่างผู้ควบคุมน้ำหนัก
* **สเปกย่อย**:
  * หน้าเว็บข้อมูลข้อผิดพลาดในการเชื่อมต่อ (LINE Webhook FAQ)
  * แบบฟอร์มสำหรับรับเรื่องร้องขอทางเทคนิค (Support Ticket Form) เพื่อให้ผู้ใช้สามารถแจ้งปัญหาระบบไปหาผู้ดูแลระบบ (Admin) ได้ทันทีเมื่อพบการติดขัด
